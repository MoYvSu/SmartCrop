# P0.5 比赛演示路径

状态：Ready

日期：2026-09-06

## 演示边界

SmartCrop 展示的是“AI 给出三种构图方向，用户选择并精修”的人机协同闭环。演示不声称模型能自动比较候选优劣、复评终稿或输出可信美学分数。

仓库内置的静物图是项目自制合成 SVG，不含第三方照片。入口分为：

- **载入实时样例**：先把样例转换为 PNG 并放入上传区，再点击“实时分析演示样例”，完整经过当前 API 与 Mock 或 Venus Worker；
- **预生成导览**：直接加载固定候选与报告，用于断网、GPU 冷启动或答辩时间受限时讲解，不调用当前模型。

结果页会持续显示来源，讲解者不得把预生成导览称为实时推理。

## 三分钟固定路径

1. **问题与目标（20 秒）**
   - 内容创作者常知道用途，却难以一次决定裁剪方向。
   - SmartCrop 不替人判断“最好”，而是把不同偏好变成可选择、可修改、可追溯的方案。
2. **输入意图（25 秒）**
   - 选择场景和发布模板；展示头像、社交封面、商品主图、演示文稿配图。
   - 切换到自定义比例，说明支持 `1:10` 至 `10:1`，随后恢复比赛选定模板。
3. **三种方向（35 秒）**
   - 展示当前方案，展开另外两个候选。
   - 说明三条偏好提示分别推理，但候选没有自动排名；选择权在用户。
4. **人工精修（45 秒）**
   - 打开三分线、中心线、对角线和安全区域中的两项。
   - 拖动或使用方向键调整裁剪框，指出辅助线不会进入成片。
   - 展示保留面积、预计输出尺寸和比例合规状态实时变化。
5. **记录决策（25 秒）**
   - 选择“主体突出”和“适配平台”，补充一句留白说明。
   - 确认并应用方案，说明服务器会再次检查比例，不合规制品不会被静默导出。
6. **结果与证据（30 秒）**
   - 下载原分辨率裁剪图和 schema `1.2` 方案文件。
   - 展示方案中的模板、人工选择、调整状态、处理耗时和客观输出尺寸。

## 用户操作速查

- 正常使用：上传 JPEG、PNG 或 WebP → 选择场景和模板 → 开始分析。
- 候选选择：展开其他构图 → 选择一个方向 → 在锁定比例下精修。
- 辅助检查：按需打开辅助线；比例状态显示“符合”后保存。
- 决策记录：按需选择一项或多项理由；补充说明是可选项，最长 200 字。
- 导出：先保存方案，再分别下载成片和 JSON；界面也会在导出前自动保存未应用修改。

## 答辩故障回退

- GPU 未就绪：使用预生成导览，明确说明没有调用模型；不等待现场恢复。
- Venus 推理失败：展示产品提供的纯手动裁剪模式，不伪造报告。
- 翻译失败：保留英文初始报告，裁剪结果仍可保存和下载。
- 网络中断：使用已打开的预生成导览完成候选选择、精修、指标和方案导出展示。

## 一致性检查

作品报告、用户手册、讲解稿和视频统一使用以下表述：

> SmartCrop 使用三种构图偏好分别生成候选，用户选择方向并完成最终精修；系统验证尺寸和比例并导出可追溯方案。

不得使用“自动选出最佳构图”“AI 证明调整后更美”“复拍前后自动评分”等未经验证的表述。
