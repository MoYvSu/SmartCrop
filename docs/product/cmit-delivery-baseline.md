# CMIT 前端收尾交付基线

日期：2026-10-17。检查起点：`d15cdea`。

本轮按用户要求，以当前前端为中心进行最后一次外观与功能审查。保持摄影编辑室的视觉方向，不再增加 Agent、跨图比较、账号或新业务模块；本记录作为这一阶段的交接基线，不表示赛事官方认证、提交完成或模型效果通过验收。

## 本轮审查结论与修复

| 已复现的问题 | 收尾处理 |
| --- | --- |
| 慢请求下，旧任务返回可覆盖重新打开的样例或新任务 | 离开任务时中止前端请求，并校验请求所属工作区；旧响应不再更新当前图片、坐标或忙碌状态 |
| 保存期间继续编辑，返回的旧坐标或说明覆盖新调整 | 保存及下载全程锁定裁剪、候选与选择依据，防重复点击；完成后显示明确反馈 |
| 轮询断线后缺少继续原任务的入口 | 增加重新连接，只查询已提交任务，不重复上传；首次提交失败保留原文件和模板供重试 |
| 裁剪框内也被压暗，与成片亮度不一致 | 只压暗框外区域；统一图像卡片舞台背景，清理候选缩略图的样式覆盖 |
| 固定比例时，单方向拖动或键盘扩大裁剪没有反应 | 统一指针与键盘缩放计算，保持比例、对角锚点和边界；补充相关几何测试 |
| 手机仅靠拖动难以精修 | 原图下增加默认折叠的“精细调整”：四向移动、扩大和缩小，按钮触控高度不少于 44 px |
| 切候选后焦点随被折叠按钮丢失 | 将焦点返回展开按钮，播报所选方向 |
| 失败时仍宣称 AI 三候选可用，过期后仍可继续点击保存 | 无可用分析时明确手动裁剪；过期后保留查看但锁定编辑、保存和下载 |
| 排队页面给出不准确的总等待上限 | 改为队列位次或任务进度，不承诺固定 120 秒；说明返回上传页不等于取消后端任务 |

补充整理：文件错误提示靠近上传区域，上传期间锁定表单；隐藏文件输入不产生重复键盘停靠；增加文本框及折叠控件的焦点样式；提高部分工具说明文字字号；隐藏手机首页与照片说明重叠的装饰性英文标签。未保存的实际调整在重新选图前会请求确认。

## 本地验证结果

- 前端自动测试 **68/68** 通过；TypeScript 类型检查、Vite 生产构建通过。
- Python 自动测试 **95/95** 通过（含随后追加的翻译保障回归；最初前端收尾时为 46/46）；Ruff 代码检查、`git diff --check` 通过。依赖产生 7 条弃用警告，无测试失败；未为此升级依赖。
- 实际 Edge/Chromium 浏览器在 **375 / 768 / 1024 / 1440 px** 检查首页、样例结果和精调展开状态：无横向溢出，图片完整加载。
- 四个尺寸均完成场景卡同步、比例输入、样例、候选切换及焦点恢复、键盘与指针裁剪、精调按钮、辅助线、确认和 PNG 下载；下载图片可解码，像素尺寸匹配当前裁剪坐标。
- 812 × 375 横屏、根字号放大至 125%、减少动态效果模式下无横向溢出。该检查不等同于全部浏览器的完整无障碍认证。
- 本机真实 Mock API 与串行 worker 在桌面、手机尺寸各完成上传、商品主图模板、精调、记录选择说明、自动保存和 JPEG 制品下载。成片 **292 × 364 px**，符合 4:5 的像素取整误差，保存后的选择说明一致。
- 浏览器另外通过六类受控异常场景：延迟保存/下载的互斥与去重、断线后原任务重连、离开后的旧响应隔离、保存时过期、模型失败时手动降级、提交失败后的文件与设置保留。其中异常由浏览器拦截响应注入，不冒充真实网络事故或真实 Venus 失败实验。
- 浏览器无未捕获脚本异常。人工查看了手机与桌面结果截图，确认裁剪框内亮度、图像舞台和精调布局。

本机证据保留在 Git 忽略的 `var/cmit-final-review/`：`visual-results.json`、`network-results.json`、两份浏览器检查脚本、各尺寸截图与实际下载图。临时 Mock 任务存于 `var/cmit-final-demo/`，不提交图片、数据库或运行产物。检查后已关闭本轮启动的本机 Mock API 与 worker，保留验证产物，未操作远端服务器。

以上为本轮提交前的本地检查结果。提交后的远端 CI 以该次提交对应的 GitHub Actions 结论为准，先前版本的 CI 成功不能代替本轮检查。

## 保留的产品与模型边界

- 公开主链路为上传一张照片、异步分析、按偏好生成候选、用户选择与精修、下载原分辨率裁剪成片和查看初始画面分析。
- 固定样例没有调用模型；Mock 仅验证界面、任务和制品链路。本轮未重新验收真实 Venus GPU 推理及其审美质量。
- 原有 DeepSeek 中文报告翻译仍保留：worker 在 Venus 生成结构化报告后仅发送报告文本进行翻译，不发送用户图片；前端保留来源标识及翻译失败后的英文原文。翻译器与降级自动测试通过，另补四项前端展示测试。本轮 Mock 浏览器验收临时禁用翻译，没有调用真实 DeepSeek API，也没有改动私有配置或密钥；本机 `.env` 当前为 `none` 且未配置密钥，服务器私有配置未核实。
- 根据随后追加的要求，已补齐“启用翻译但缺密钥自动降级”及“翻译不占用推理时限”两处保障；实现、迁移与测试边界见 [ADR-0008](../decisions/0008-optional-translation-failure-isolation.md)。这属于本轮收尾修复，不新增用户功能。
- 不提供复拍前后优劣比较、终稿复评、自动候选排名、美学评分或普通用户 JSON 导出。
- 选择依据只随当前临时任务保留，不用于训练。本轮不引入模型改进计划或数据捐赠，不改变既有保留与清理政策。
- 重新连接不保证跨刷新或跨设备恢复；返回首页会放弃前端等待，并不代表取消已提交的后端任务。
- 这仍是响应式网页，不是原生移动 App，也不承诺离线编辑。浏览器验收以本机 Edge/Chromium 为准，未覆盖所有 iOS Safari 或移动硬件。

本轮以修复操作缺陷、交互反馈、移动精修和交接记录收尾。不再将扩展功能列为本次 CMIT 跟进的继续实施事项；未来如需推进另行明确范围。
