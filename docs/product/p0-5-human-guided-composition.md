# P0.5：人机协同构图助手

状态：In progress

日期：2026-09-06

## 产品定位

SmartCrop 是面向内容创作者的场景化 AI 构图决策助手：系统按照不同构图偏好分别生成候选，用户选择方向并完成精修，服务器输出满足目标规格的成片与可追溯方案。

产品不宣称 Venus 能可靠比较复拍前后图片、自动判断候选优劣或稳定完成终稿复评。AI 提供方向，人负责最终审美决策。

## 已确认的能力边界

- `balanced`、`subject`、`story` 使用三条不同偏好提示词分别执行推理；
- 候选可能相似，这不再作为 P0.5 的阻断条件；
- 产品必须保证候选坐标合法、目标比例正确、用户可以选择和精修、下载制品正确；
- 终稿复评不能作为公开功能依赖。后端实验接口暂时保留，但前端默认隐藏；
- 不提供跨图比较、自动排序、审美分数或未经验证的效果提升声明。

## 目标体验

```text
选择创作目标
    -> AI 按三种偏好分别生成构图
    -> 当前方案突出显示，其他方案按需展开
    -> 用户选择并在比例锁定下精修
    -> 查看构图辅助信息
    -> 导出原分辨率成片与决策方案
```

## 分阶段路线

### 第一阶段：收敛可信主链路

状态：Implemented（2026-09-06）

- 从公开界面移除终稿复评入口和相关文案；
- 初始报告统一称为“画面分析”，用户调整后明确说明报告仍对应 AI 初始分析；
- 当前候选突出显示，其余候选默认收起并允许随时展开；
- 选择某个候选后保留其策略标识，后续手动调整不会丢失选择来源；
- 方案 JSON 记录 `selection_mode: human`，不再包含终稿复评结果。

### 第二阶段：增加可解释的构图辅助

状态：Planned

- 可切换的三分线、中心线、对角线和安全区域；
- 显示裁剪保留面积、原始尺寸、目标尺寸和比例合规状态；
- 将比例选项升级为头像、社交封面、商品主图、演示文稿配图等发布模板；
- 保留自定义比例入口，不把产品限制在平台模板内。

### 第三阶段：形成比赛演示闭环

状态：Planned

- 用户可记录选择理由，例如主体突出、环境完整、画面平衡或适配平台；
- 在导出方案中保存选择依据、人工调整状态和处理耗时；
- 提供使用已授权样例的演示模式，并明确区分实时推理与预生成示例；
- 提供客观效果面板，不展示没有可靠依据的美学分数；
- 准备与作品报告、用户手册和演示视频一致的固定答辩路径。

## 第一阶段验收

- 结果页没有终稿复评按钮或“复评后更好”的暗示；
- 三种构图偏好仍分别进入 Venus 推理流程；
- 默认只突出当前方案，其他候选可通过键盘和鼠标展开、选择、收起；
- 用户选择候选、手动调整、保存和下载的既有链路不回退；
- 调整后的报告明确标注其解释范围；
- 前端测试、类型检查与生产构建通过；
- 现有暖色中性设计系统、焦点样式和减少动态效果支持保持不变。

## 暂不实施

- 多图片或复拍前后构图比较；
- Venus 候选自动排序和“最佳方案”承诺；
- 用户偏好训练、账号历史和云端作品库；
- 多图批量处理与正式移动端工作台。
