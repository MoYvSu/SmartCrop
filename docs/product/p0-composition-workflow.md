# P0：意图驱动的构图工作流

状态：Superseded by P0.5

日期：2026-09-05

> 2026-09-06 的真实模型验证确认终稿复评不够可靠。公开产品已转向
> [P0.5 人机协同构图助手](p0-5-human-guided-composition.md)，本文件保留为历史设计记录。

## 用户链路

1. 上传单张图片，并选择使用场景与成片比例；
2. 查看平衡构图、主体优先、环境叙事三个策略候选；
3. 选择候选，在锁定比例下移动或缩放裁剪框；
4. 保存原分辨率裁剪，可将终稿作为独立图片重新排队复评；
5. 下载裁剪图与包含意图、最终裁剪、初始报告和终稿复评的 JSON 方案。

## 能力表述边界

- `mock`：只证明 API、队列、比例约束、交互与制品链路可运行；
- `unverified`：Venus 路径已接入，但多策略差异性和终稿复评质量尚未通过真实 GPU 验收；
- `verified`：仅在真实 Venus 验收集通过后，由部署方显式设置
  `SMARTCROP_P0_CAPABILITIES_VERIFIED=true`。

P0 不宣称 Venus 能对两张不同照片进行相对优劣排序。终稿复评是对裁剪后图片进行一次新的单图分析，前后报告并列展示，由用户作最终判断。

## GPU 恢复后的最低验收

- 同一图片、五类场景与五种比例均可返回有效且越界安全的候选；
- 非自由比例候选与下载成片的像素宽高比一致；
- 三策略在人工可判断的测试图上具有稳定、可解释的差异，不能只是提示词换名；
- 终稿复评只描述终稿可见内容，不引用不存在的前序对话或伪造跨图比较；
- 固定图片集重复运行，记录失败率、重复候选率、坐标有效率与人工偏好结果。

结构化探针命令：

```powershell
$env:SMARTCROP_ACCESS_CODE = "your-code"
.\.venv\Scripts\python.exe scripts/run_p0_capability_probe.py `
  --base-url https://your-host `
  --limit 30
```

输出写入被忽略的 `var/p0-capability/`。探针通过仍不能自动将能力状态改为
`verified`；还必须填写策略差异和终稿报告真实性的人工复核结果。
