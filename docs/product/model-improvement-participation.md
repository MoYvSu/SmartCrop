# 模型改进计划：自愿数据参与边界

状态：Deferred

日期：2026-09-07

## 当前决定

P0.5 不收集长期训练数据，也不在上传、确认或下载过程中加入默认勾选项。原图、候选、最终裁剪、选择理由和备注仍属于一小时临时任务，按现有清理规则删除。

`selection_confirmed` 只表示用户确认成片，不能解释为训练授权。填写选择依据、下载裁剪图或使用共享访问码同样不构成同意。Mock、固定使用样例、失败任务和未确认任务不得进入真实训练集。

因此本轮不在界面放置“模型改进计划”复选框。仅有文案而没有独立存储、撤回和用途版本控制的复选框会造成虚假同意。

## 未来可实施的最小方案

若后续建立数据闭环，应在成片确认后提供独立操作“自愿贡献本次样本”，默认关闭，且拒绝参与不影响裁剪功能。确认前必须清楚说明：

- 保存哪些内容、用于哪一种模型任务以及保留多久；
- 仅用于 SmartCrop 内部、非商业构图研究，不用于身份识别、广告画像或第三方共享；
- 用户确认其拥有图片的必要处置权；
- 如何凭独立回执撤回，以及样本进入已发布模型后无法精确消除既有参数影响的限制；
- 数据范围或用途变化时需要重新同意。

服务端应记录同意文本版本、用途版本、数据范围、时间和文本校验值，并返回不可猜测的撤回凭据。撤回凭据不得进入 URL、访问日志或训练清单。捐赠数据必须进入与临时任务完全分离的存储；训练流程不得扫描现有任务目录。

撤回必须覆盖原始池、隔离池、派生标签和尚未用于训练的数据快照，并在上线前明确处理时限。已经参与训练的数据应从所有未来数据集和后续模型版本中排除；产品不得承诺能够从已经发布的模型参数中精确消除单一样本影响。备份按公开期限到期，最小化撤回墓碑用于防止恢复备份时把样本重新加入数据池。

## 数据最小化

直接裁剪数据与偏好比较数据必须分开：

- 直接裁剪样本可以包含去除元数据后的原图、创作意图、最终裁剪框和人工调整状态；
- 只有用户明确看过多个候选并作出比较选择时，才能形成候选偏好标签；
- 结构化选择理由可作为可选标签；自由文本备注、报告正文、访问码、文件名、路径、网络标识和日志默认排除；
- 裁剪图不重复保存，可由原图和坐标重建；
- 每条样本记录后端、模型、提示词和同意版本，以支持审计和数据集隔离。

## 主动学习边界

主动学习只负责从已明确捐赠的数据池中挑选值得人工复核的样本，不能先收集再补同意。当前 Venus 没有经过验证的可信不确定度，因此第一版只能使用可复核信号，例如人工调整幅度、候选与最终框的 IoU、不同发布模板的覆盖不足；不能把这些代理量宣传成模型置信度。

训练、验证和固定测试集必须版本化并做近重复隔离。任何新模型仍需独立验收，不能因为收集了用户选择就宣称模型已持续学习或自动变好。

## 实施前门禁

以下能力全部具备后，才能增加公开入口：

1. 独立的同意、捐赠、隔离、启用和撤回状态机；
2. 与一小时任务存储隔离的数据目录和数据库；
3. 字段白名单、图片元数据清理、访问审计和明确保留期限；
4. 可重复、幂等且不泄露撤回凭据的流程，覆盖原始、隔离、派生、快照和备份边界，并保证未来训练清单不再包含已撤回样本；
5. 对普通任务不产生长期文件的自动化测试；
6. 真实 Venus、Mock、固定样例和失败任务的严格来源门禁。
