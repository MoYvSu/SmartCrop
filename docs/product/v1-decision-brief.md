# SmartCrop V1 决策简报

状态：Approved

批准日期：2026-09-01

## 产品目标

把 Venus 论文模型整理为一条可信、可展示的产品链路，而不是重新做研究训练平台。用户上传一张图片后，得到一个 AI 最佳裁剪、可手动微调的裁剪框、原分辨率裁剪图和页面内美学分析。

V1 用于研究、内部展示和受控公开演示，不发布、不商用。数据集已经授权，但数据与模型不随产品仓库分发。

## 用户与体验

- 正式支持电脑端浏览器；手机端只保留 API 兼容性和不支持提示。
- 每次只处理一张 JPEG、PNG 或 WebP，最大 20 MB。
- 结果页左右对照原图与裁剪预览。
- AI 只给一个最佳框；用户可移动框并通过四个角缩放。
- 用户调整不触发重新分析，报告必须注明它解释的是 AI 初始建议。
- 浏览器只做实时预览，下载图由服务器基于规范化原图生成。

## 报告

报告内容统一使用英文，由 Venus 查看原图后直接生成，不翻译或整理另一段原始评论。页面栏目名称保持简体中文。报告不展示总分、星级或伪精度数字，结构固定为：整体观察、画面优点、主要问题、裁剪理由、下次拍摄建议。

报告只在页面展示，不提供下载。若模型失败，系统明确显示失败原因并允许纯手动裁剪；此时不得伪造报告。

## 运行约束

- 典型演示服务器为一张 RTX 4090。
- 模型工作进程常驻且串行执行，每次只运行一个任务。
- 最多允许 5 个等待任务；第 6 个新请求返回明确的稍后重试提示。
- 排队时间与运行时间分开表达；运行开始后目标 P95 不超过 60 秒。
- 单任务 120 秒硬超时，超时即终止模型子进程并重新加载。
- 上传、预览、裁剪、报告和任务记录保留 1 小时，之后自动清理；不提供历史页。

## 访问与部署

- 受控公开演示使用可替换的共享访问码。
- 对外必须经 HTTPS 反向代理，API 本身只监听回环或受信网络。
- 模型可部署在 AutoDL 等 GPU 平台，因此 API 与 worker 保持清楚的进程边界。
- V1 使用同机 SQLite + 文件系统共享任务，不引入 Redis；未来跨主机时可替换存储层。

## 验收门槛

- 契约、图像与 API/worker 集成测试全部通过。
- 前端类型检查、单元测试和生产构建通过。
- 固定 30 图在真实 GPU 部署上完成上传到制品下载的全链路回归。
- 回归失败、超时和损坏图片不能显示为成功。
- 人工检查裁剪框、报告语言和最终下载图，不用 Mock 结果代替真实模型结论。

## 明确不做

- 账号系统、个人历史、多图批量、手机端正式 UI；
- 多个候选框、比例预设、旋转、透视或完整图片编辑器；
- 报告 PDF/Markdown 下载；
- 模型分数、社交分享、商业计费；
- 将论文数据、模型权重或用户上传提交到 Git。
