# 宽屏摄影工作室 V2：第二阶段账号与作品接入

日期：2026-10-17。范围：真实演示账号、独立作品草稿、归档成片与恢复编辑。保留第一阶段的五页结构和视觉语言，不在这一阶段补造摄影统计或创作画像。

本记录覆盖[第一阶段](desktop-workspace-v2-phase-1.md)中“账号与长期作品未接入”的现状说明；整体设计仍见[主设计](desktop-workspace-v2.md)与[五页附录](desktop-workspace-v2-pages.md)。后端安全、保留和版本行为以实际服务及回归测试为准，不将界面文字当作能力证明。

## 真实创作的入口

- 展示首页仍允许直接体验固定样例，样例不调用当前模型，也不能存为真实账号项目。
- 自己的照片先登录，再导入为独立作品草稿；登录前已选择的照片可以在同一页面登录后继续导入。
- 导入成功直接进入手动工作台，不先占用 GPU，也不要求模型推理成功。
- 首页指南改为“导入，建立草稿 → 精修，参考按需 → 归档，下载成片”。不会把三种 AI 候选写成每次创作的必经步骤。
- 工作台仍有裁剪、成片预览、对照三种画布视图；右侧工具宽度、辅助线、精细调整、候选与折叠报告沿用第一阶段。

## 登录与共享范围

新增登录界面使用相同暖白、森林绿和摄影素材，装饰照片明确标为灵感展示。表单只有实际支持的用户名、密码与登录，不添加无实现的注册、找回密码或第三方登录按钮。

- 演示用户名可预填 `demo`，密码始终为空，不在代码、文档或页面中提供真实密码。
- 用户名与当前密码提供标准自动填充标记；不拦截粘贴，可用密码管理器。
- 显示／隐藏密码为有名称、可键盘操作的原生按钮；登录中禁用输入和重复提交。
- 登录失败在表单附近显示可读错误，保留用户名输入，供用户修正后重试。
- 登录页、侧栏、概览、作品页与摄影档案持续说明：演示账号共用作品库。同一账号的使用者都能查看和修改照片与作品，不能误认为私人空间。
- 侧栏与档案显示服务返回的真实用户名和显示名；退出有明确进行中状态。

共享身份仅用于演示，不代表已经提供多用户独立私密空间或用户权限管理。不要引导用户上传私人敏感照片。

## 草稿、归档与 AI 的关系

导入照片后，作品不依赖旧临时任务的路径恢复。工作台读取项目自身保存的图片与草稿；刷新、重新登录、从作品库打开时恢复项目记录。

1. 调整裁剪框、作品名称和可选选择依据后，编辑器等待短暂停顿再自动保存；界面显示“有更新待保存／正在保存草稿／草稿已保存／保存失败”等实际状态。
2. “保存草稿”提供主动保存入口；“完成并归档”生成正式成片。两者不是同一个动作，不能用“已确认临时方案”冒充归档。
3. 归档后继续编辑只改变草稿，已归档成片不悄悄替换。出现实际变更后，可“保存新版本”；未变更时禁用重复归档。
4. “下载裁剪图”针对当前草稿；作品卡“下载归档成片”针对已归档的固定成片。两种下载不混用路径。
5. AI 参考按需请求。请求进行时可继续本地精修；模型返回只更新参考，不自动覆盖当前裁剪或选择依据。
6. 明确选择候选才改变取景，替换已调整的草稿有确认。参考报告仍解释模型最初建议，不对用户最终成片打分或复评。

持久模式中三个方向一律标为“构图参考”，不将默认第一条冒充用户当前方案；第一条也有“采用此构图参考”按钮，其余方向按需展开。选择会保存原始参考来源，即使临时任务已清理仍可恢复。

编辑期间的同步、切换项目前的保存、并发版本冲突和登录过期恢复由编辑器负责。遇到冲突不能默默采用“最后写入者覆盖”而丢失当前调整；重载服务器版本应先明确告知会放弃本地改动。

## 五页的当前内容

### 创作概览

- 登录后优先显示真实项目的已归档数、草稿数、待更新归档数，以及最近更新的最多六个项目。
- 同一项目的多次编辑和版本不重复计为多件作品；固定样例不进入这些计数。
- 未读取、读取中或读取失败用 `—` 表示统计未就绪，不把初始化空数组当作真实的零。
- 数据接口建议以 `projects: undefined` 表示尚未成功读取；只有成功返回空列表才传 `[]`。错误／加载状态独立传递。
- 最近项目可打开继续编辑，“查看全部作品”进入作品页；加载与失败有状态说明和重新读取入口。

### 构图工作台

- 图像仍优先于工具；持久项目显示实际作品名称、保存状态、手动精修和可选 AI。
- 脏草稿用“有更新待保存”，不再显示临时方案的“未应用修改”。归档进行中只在归档按钮显示“正在归档”，不同时把草稿按钮标成正在保存。
- 持久项目不显示“一小时后清理／临时任务过期”规则；临时分析作业的清理不得被解释成删除已保存作品。
- 图像分析、拍摄参数仍明确未接入，不制造直方图、EXIF、审美分或清晰度分。

### 我的作品

- 列表来自当前账号真实项目，支持全部／已归档／草稿筛选和标题搜索，默认按最后更新时间排序。
- 草稿卡显示原图预览并明示“原图预览”，不把原图包装成已生成成片；已归档卡优先展示归档成片。
- 卡片区分原图尺寸、当前版本和更新时间；归档后有新草稿时提示“草稿有新调整，归档成片保持不变”。
- 提供继续编辑、归档成片下载和删除。删除前确认包含草稿、所有版本与图片，并指出会影响同一账号的所有使用者、不可撤销。
- 未读取、加载中、读取失败、真实空库、筛选无匹配分别表达；失败可重试，不误称“没有作品”。
- 登录后若没有单独的当前样例会话，不再额外放一个“还没有正在进行的创作”空块。真实项目列表已承担恢复入口。

### 摄影洞察与摄影档案

- 洞察目前解释值得观察的亮度、色彩、画幅和选择信息，不将作品数包装成已经接通的摄影分析系统。
- 档案显示真实账号与共用说明；工作台初始设置依旧是产品默认值，不伪装成用户保存的偏好。
- 图像统计、EXIF、设备档案和可编辑创作偏好尚未接入。画像只限未来有依据的创作偏好，不推断人格或敏感属性。

## 保存与隐私边界

- 持久项目的照片、草稿与归档成片保留至主动删除；这与临时 AI 任务的清理规则分开。
- 项目导入副本去除原图元数据，不保存 GPS。当前不应宣称能恢复原始 EXIF 或为缺失参数补值。
- 当前上传不进入训练集；未增加“模型改进计划”默认授权，也不将用户作品自动回流训练。
- 作品图片和下载需要有效登录；共享账号中的内容对所有同账号使用者开放。退出后不能继续访问受保护的项目资源。
- 本地缓存与在途请求不等于已保存成功，保存失败仍必须明确提示；不得仅因按钮点击就显示“已归档”。

- 前端：147 项测试通过，TypeScript、Vite 生产构建及 Ruff 通过；其中登录、侧栏、内容页、导入、工作台组件合计 44 项重点结构／纯函数用例。请求层另覆盖 CSRF 同步、取消和分页。
- Edge 实际浏览器共 61 组功能／布局检查，零页面运行异常。宽屏 1366 × 768、1440 × 900、1920 × 1080 和 1024、768、375 窄屏检查通过，登录另验 812 × 375 横屏；无横向溢出，工作台宽屏照片可见，主区域与 ID 不重复。
- 实际完成无 AI 导入、改名、键盘裁剪、选择依据、自动草稿、刷新恢复、退出重登、归档 V1/V2、旧版本固定下载、可解码成片及继续精修。
- 延迟保存响应时继续编辑，最后一笔仍提交；第二标签页旧版本写入返回 409，不覆盖第一页面；显式重新载入才能丢弃冲突草稿。
- 重新载入等待期间锁定输入与裁剪，避免丢弃确认之后的新编辑；取消打开项目后再导入照片不会残留加载状态；密码显示／隐藏可用键盘操作。
- 刷新作品列表期间导入新照片，旧列表响应不能抹去刚建项目：发生本页保存／导入／删除时重新读取列表，避免慢响应制造“作品消失”的假象。
- 跨标签登录轮换后同步写入校验令牌，保留本地调整并由用户主动重试，不静默重复归档或导入；会话失效后重新登录可继续提交页面内未保存的调整。
- 已真实重启本地 API 与 worker，再打开之前作品；定向清理该验收项目的临时任务及目录后，源图、编辑、下载、报告、参考选择及归档 V2 均仍正常。该清理只针对验收任务，不靠等待一小时制造验证结论。
- AI 验证使用 Mock：新结果不覆盖当前草稿；拒绝采用保留原框，首个及其他方向可主动采用，刷新后保留来源与选择。未调用真实 GPU 或外部翻译服务。
- 验证未登录项目／关联任务／图片均不可读，缺少校验和跨源写入拒绝，项目任务不能通过旧复评接口派生匿名图片；保护响应为 private/no-store。
- 真实列表的搜索、状态筛选、删除取消／确认、删除后专属资源不可读均通过；删除的是本轮新建的可丢弃验收项目。
