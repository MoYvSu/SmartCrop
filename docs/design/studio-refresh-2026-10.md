# 摄影编辑室 UI 更新记录

日期：2026-10-15

## 目标

面向 CMIT 数媒比赛移动/网页应用开发方向，将原先以单一上传卡为主的页面丰富为有摄影气质的创作工作台。本轮聚焦外观、内容组织和不同屏幕的适配，业务能力继续沿用已经实现的上传、异步分析、候选选择、裁剪精修与下载。

原来的暖白极简页面虽然清楚，但缺少照片呈现、使用情境和操作节奏。新的首页先让用户看到“用它能做什么”，再自然进入上传；结果页继续优先展示原图和裁剪图。

## 页面方案

视觉方向为“摄影编辑室”：`#F6F5F1` 暖白底色、`#275C4C` 森林绿主色、浅鼠尾草的次级面、石墨文字，以及少量低饱和酸橙点缀。保留照片工作区的中性深色底，减少界面本身对照片判断的干扰。

首页依次为导航与三步进度、摄影首屏与创作表单、发布场景、使用指南和创作宣言。照片、信息密度和内容节奏共同增加丰富度；没有加入虚构数据或模型评分。

三个场景入口直接复用现有参数：社交封面、演示配图、商品主图。用户选择后可在上方表单看见同步后的发布模板与使用场景；只有选择自己的文件并点击分析，才会启动任务。原“查看使用样例”仍独立存在，并明确标识固定展示结果。

结果页继续使用“图像在上、候选与辅助工具在下”的顺序，统一工作区、报告、按钮和选中状态的风格。已有的辅助线、尺寸信息、选择理由、手动精修和原图下载逻辑继续保留。

## 响应式范围变更

早期 V1 文档约定手机只显示不支持提示。本轮将其替换为可操作的响应式网页：375 px 起显示完整流程，上传表单与图像对照单列，工具栏自动换行，报告进入正常页面滚动。该范围仅指移动浏览器适配，并未新增原生 App、离线功能或独立手机端。

设计实现规范见 [studio 页面覆盖](../../design-system/smartcrop/pages/studio.md)，保留早期 MASTER，避免抹去原设计记录。

## 素材与真实性

首页摄影素材是静态视觉参考，固定取景线明确注明“构图示意 · 非 AI 推理结果”；场景区说明最终分析使用用户上传的照片。首页照片不作为模型成功案例或真实推理证据。素材来源、作者和使用说明随图片一同维护。

界面不提供复拍前后优劣比较、终稿复评、审美分数或训练数据上传入口。清理政策与原有产品说明一致，不引入新的数据保留承诺。

## 交付检查

- 保留上传、粘贴、拖放、比例模板、自定义比例、样例与正式任务边界。
- 检查首页与样例结果页在 375、768、1024、1440 px 下的排版、横向溢出和主要操作可见性。
- 检查 44 px 触控范围、键盘焦点、输入可读性、图片替代文本及减少动态效果设置。
- 运行已有前端测试、类型检查和生产构建。视觉检查不能代替真实模型效果验证。

### 2026-10-15 执行结果

- 现有前端测试 29/29 通过，TypeScript 检查和 Vite 生产构建通过。
- 使用实际浏览器检查 375、768、1024、1440 px：首页和结果页均无横向溢出，图片加载完整。
- 四个尺寸均验证场景卡同步模板和使用场景、自定义比例输入、固定样例、候选切换、方向键微调、辅助线开关、方案确认和裁剪下载。
- 812 × 375 横屏在根字号放大至 125% 且启用减少动态效果时无横向溢出。
- 主按钮白字与深绿底的对比度为 7.72:1，正文与暖白底为 12.95:1，次级文字为 5.00:1；均高于普通文字 4.5:1 要求。
- 在本机 Mock API/worker 上，1440 px 和 375 px 均完成真实文件上传、商品模板分析、确认与服务器制品下载；下载 JPEG 可解码，输出 308 × 384 px，符合 4:5 的像素取整允许误差。
- 浏览器无未捕获脚本异常。此次未重新测试 Venus GPU 模型，Mock 验证仅证明界面、任务与制品链路。

本机截图与机器可读结果位于被 Git 忽略的 `var/ui-studio-review/`；其中 `home-1440.png` 为完整首页，`result-375.png` 为手机样例工作台，`results.json` 与 `mock-flow-results.json` 记录检查结果。参考作品展板仅保留在本机检查目录，没有随产品分发。
