# SmartCrop 宽屏摄影工作室导航与视觉设计

日期：2026-10-17

状态：方案已确认，按用户授权分阶段实现。五页导航和共享视觉、演示账号、独立作品、浏览器像素分析与真实归档洞察已接入；第四阶段完成账号偏好、新建自动采用和主色气质文案，EXIF 与设备档案仍待实现。进度见[第一阶段](desktop-workspace-v2-phase-1.md)、[第二阶段](desktop-workspace-v2-phase-2.md)、[第三阶段](desktop-workspace-v2-phase-3.md)与[第四阶段交付记录](desktop-workspace-v2-phase-4.md)。

## 设计目标与阅读顺序

SmartCrop 面向需要整理、理解和精修照片的摄影爱好者与内容创作者。保留现有首页的摄影编辑室气质，把进入应用后的体验组织成持续使用的摄影空间。图像数据、AI 参考和个人记录平行存在，不要求 Venus 解释或统领所有功能。

- 本文件定义导航、公共布局、视觉语言和跨页交互。
- [五个页面的功能与布局](desktop-workspace-v2-pages.md)定义首屏、低保真线框、具体操作和异常状态。
- [产品范围与数据边界](../product/photography-workspace-v2.md)定义演示账号、草稿与作品、数据来源和待确认项。
- 当前已实现界面的视觉依据仍是 [摄影编辑室页面规范](../../design-system/smartcrop/pages/studio.md)。本稿只扩展下一版设计，不覆盖当前实现记录。

## 体验原则

1. 以照片组织内容。工作台的主角是当前照片，作品页的主角是作品，洞察页的主角是可以追溯的统计。
2. 首页与应用共享配色、字体、图标和留白节奏，允许展示页与操作页具有不同信息密度。
3. 工具功能平行。浏览器图像分析、手动裁剪、可选 AI 建议、报告翻译和档案保存各自显示状态。
4. 一次编辑留下可继续的草稿；用户确认后才成为正式作品。历史不等于每次点击的操作流水。
5. 图表应能解释、筛选或定位照片。没有来源和后续动作的装饰性图表不进入首版。
6. 用户画像表达创作设置与已发生的选择，不推断人格，不衡量摄影水平，不宣称自动学习审美。

## 导航结构

### 展示首页与应用首页

“展示首页”指当前暖白与森林绿的品牌入口，保留摄影大图、场景卡和使用指南；“创作概览”指登录后的个人工作室首页。两者不是同一页面，也不重复堆放同一套宣传内容。

```text
展示首页 /
  ├─ 进入工作室 → 登录 /login → 创作概览
  ├─ 已登录 → 继续创作或进入工作室
  └─ 查看使用样例 → 无需模型的固定操作示例

工作室 /studio
  ├─ 创作概览
  ├─ 构图工作台
  │    ├─ 导入照片
  │    └─ 打开某个项目 → 编辑、分析、归档与下载
  ├─ 我的作品
  │    └─ 作品详情 → 查看版本或继续编辑
  ├─ 摄影洞察
  │    └─ 点击统计 → 我的作品中的相应筛选结果
  └─ 摄影档案
       ├─ 基本资料与设备
       ├─ 创作偏好
       └─ 练习与复盘清单
```

以下为完整页面地址规划。第一阶段实现五个一级页面地址及 `/studio` 入口；含 `:projectId` 的持久项目详情地址和登录仍待后续，不代表 API 承诺：

| 位置 | 规划地址 | 主要动作 | 侧栏选中项 |
| --- | --- | --- | --- |
| 创作概览 | `/studio/overview` | 继续最近草稿或新建创作 | 创作概览 |
| 新建工作台 | `/studio/workbench` | 导入照片 | 构图工作台 |
| 项目工作台 | `/studio/workbench/:projectId` | 精修当前照片并完成归档 | 构图工作台 |
| 作品列表 | `/studio/library` | 查找或整理作品 | 我的作品 |
| 作品详情 | `/studio/library/:projectId` | 查看最终版本，进入编辑 | 我的作品 |
| 摄影洞察 | `/studio/insights` | 查看规律并追溯作品 | 摄影洞察 |
| 摄影档案 | `/studio/profile` | 修改偏好和练习目标 | 摄影档案 |

作品详情和练习清单是下级内容，不增加第六、第七个主导航。`/studio` 默认进入创作概览。固定使用样例、示例作品库、真实项目分别标识，不能因它们共用画布而混用保存或统计规则。

作品列表中的详情优先用右侧抽屉展开，保留原列表位置；同时更新为详情地址。直接访问详情地址或刷新时仍能打开同一项目，关闭抽屉返回原筛选列表，不另造一套无地址的详情状态。

### 导航行为

- 展示首页品牌标识回到 `/`；应用内另有明确的“返回展示首页”，不会把每次点品牌都当成清空工作区。
- 左侧五项顺序固定，使用图标加中文名称；当前项同时显示底色、文字加重和位置标记。
- 侧栏底部放演示账号说明、帮助和退出。退出与删除、重置等危险操作不混在主导航中。
- 顶栏只放当前页面或项目名称、保存状态和账号菜单，不再复制一套横向主导航。
- 全局三步进度条不延伸到作品、洞察与档案页。任务进度只在工作台的 AI 参考区域出现，不暗示图像分析必须先经过 AI。
- 返回作品列表时恢复筛选、排序和滚动位置；从洞察跳转作品列表时携带日期、来源和分类条件，并提供返回洞察的入口。
- 登录成功返回原定应用页面；登录过期不清空仍在内存中的编辑内容，恢复登录后再确认保存。未保存内容不能跨刷新保证恢复。

## 宽屏布局骨架

主设计尺寸为 1440 × 900；同时检查 1366 × 768 与 1920 × 1080。以宽屏鼠标、键盘交互为主，不安排移动端专属布局、原生 App 或跨设备同步；现有窄屏可操作性不作为改版时可随意破坏的部分。

| 区域 | 尺寸与规则 |
| --- | --- |
| 应用侧栏 | 216 px，保持五个入口和底部账号区可见 |
| 应用顶栏 | 64 px，为内容与焦点预留空间 |
| 内容内边距 | 默认 32 px，小宽屏可缩到 24 px |
| 主要分栏间距 | 24 px；同组组件间距 8 或 16 px |
| 工作台右工具区 | 320 px；不能通过压缩主画布迁就长报告 |
| 普通页面内容 | 在可用空间内舒展，阅读与表单列不过度拉宽；大屏内容区上限约 1536 px |
| 页面标题 | 同级固定字号与间距；不在每页重复一个巨型宣传标题 |

工作台不受普通阅读页 1536 px 的内容上限约束，优先把额外空间留给画布，工具区仍为 320 px。1920 px 视口下画布区约 1296 px，照片本身仍按可用高度完整适配，不强行放大或裁掉上下边缘。

1440 px 下，216 px 侧栏与左右各 32 px 留白后，内容区约 1160 px；工作台分为约 816 px 画布区、24 px 间距与 320 px 工具区。1366 px 下画布区约 742 px。若文字放大或窗口继续收窄，应收起右侧非关键内容，而不是压缩所有文字或强行保持三列。

```text
┌──────────┬─────────────────────────────────────────────────┐
│ 品牌     │ 当前页面或项目            保存状态     账号菜单  │
│          ├─────────────────────────────────────────────────┤
│ 创作概览 │ 页面标题与一项主要操作                          │
│ 构图工作台│                                                 │
│ 我的作品 │ 页面主要内容                    情境信息或工具   │
│ 摄影洞察 │                                                 │
│ 摄影档案 │                                                 │
│          │                                                 │
│ 帮助     │                                                 │
│ 退出     │                                                 │
└──────────┴─────────────────────────────────────────────────┘
```

一级页面优先使用页面主滚动。右侧内容先通过标签和折叠减少长度，避免出现整页、卡片、卡片内部同时滚动。1366 × 768 首屏须看见照片主体及核心编辑操作，不能先滚过一屏工具才能操作照片。

## 首页与工作台的统一方式

### 保留的视觉语言

| 视觉元素 | 展示首页 | 工作台与其他应用页 |
| --- | --- | --- |
| 暖白纸面 | 承托照片与宣传内容 | 承托画布外围、表单、图表与列表 |
| 森林绿 | 品牌和主要入口 | 当前导航、主要操作与清楚的选中状态 |
| 摄影大图 | 场景化封面 | 用户当前照片、作品封面或最近项目 |
| 留白与网格 | 宽松的编辑杂志节奏 | 更紧凑，但仍以明确分组和对齐组织工具 |
| 字体与图标 | 系统中文字体、统一线性图标 | 同一字体栈、字重层级与图标族，不切换成另一套后台主题 |
| 说明文案 | 讲清使用价值 | 讲清操作结果、数据含义和当前状态 |

不把首页的所有装饰搬进编辑器。展示首页的大照片承担情境，工作台的照片承担操作；靠共同的配色、材质与排版建立连续性，不靠两页拥有相同卡片数量。

### 工作台的视觉收敛

- 取消“外层大白卡包着两张图片卡、再接一串表单”的主结构，改为一个连续的编辑区域。
- 默认一张大画布，支持“裁剪”“成片预览”“对照”模式。对照按需开启，仍能看到原图与裁剪结果，不强迫用户长期面对两块同权重的大图。
- 照片舞台保留 `#202622` 深色，只用于图像边界和观看背景；右侧工具、标题和报告继续使用暖白，不把整个应用改成深绿或暗色。
- 手动移动、缩放、撤销、重做与辅助线靠近画布；AI 候选靠近相应照片，默认只突出当前方向。
- 长报告放在“AI 参考”的折叠区域；尺寸、选择理由和 EXIF 使用紧凑信息组，不再每组一张同权重大卡片。
- 当前模式、图表范围、保存状态必须可见。省略重复解释，不能省略必要来源与错误提示。
- 选择依据是可选记录，不成为下载或归档的必填问卷。

### 视觉标记

| 用途 | 值或尺度 |
| --- | --- |
| 页面底色 | `#F6F5F1` |
| 面板底色 | `#FFFEFA` |
| 主要操作 | `#275C4C`，悬停沿用现有更深绿色 |
| 选中浅底 | `#E5ECDF` |
| 主文字 | `#252D29` |
| 次级文字 | `#626C64` |
| 图像舞台 | `#202622` |
| 状态错误 | 沿用现有危险色，始终配文字或图标 |
| 字号 | 展示标题 48–55 px；应用页面标题 28–32 px；分组标题 18–20 px；正文 14–16 px；辅助说明至少 12 px |
| 间距 | 4、8、16、24、32、48 px；同一层级统一使用 |
| 圆角 | 操作控件 8–10 px；普通面板 12–16 px；首页视觉块可保留 16–22 px |

已核算这些静态文字与背景的明暗对比：主文字／页面底色约 12.95:1，次级文字／面板约 5.41:1，面板浅字／森林绿按钮约 7.65:1，森林绿文字／选中浅底约 6.39:1，均高于普通正文的 4.5:1 目标。此项只验证色值组合，不替代后续对悬停、禁用、照片叠字和实际页面的检查。

数据本身可以有不同颜色：色相图使用实际色相，RGB 使用通道颜色，品牌绿用于操作和导航。不能为了“全绿色统一”而把色彩信息编码抹掉；不同序列同时使用文字、线型或标记区分。

## 登录与展示入口

登录是五个主页面之外的支持页面。沿用首页暖白、森林绿与摄影素材，左侧使用静态摄影封面和简短说明，右侧为紧凑登录表单，不引入霓虹渐变或复杂动画。

- 仅用户名、密码、显示密码、登录和返回首页。不放不可用的注册、短信、社交登录或找回密码入口。
- 允许粘贴与密码管理器；标签始终可见，密码错误不清空用户名。
- 显示“演示账号共用作品库，请勿上传私人敏感照片”。账号密码不嵌入前端素材或设计文档。
- 登录后默认进入创作概览；已有目标页面时返回目标页面，不能遗失正在处理的项目。
- 展示首页保留“进入工作室”主入口和单一“查看使用样例”次入口。当前上传卡所在位置可保留创作入口的视觉构图，但真实持久上传安排在登录后，避免访客不知情保存到共享账号。
- 示例操作不自动成为账号作品，不改变示例统计，也不在后台偷偷提交模型任务。

## 跨页创作与保存流程

```text
登录 → 导入照片 → 自动建立项目草稿
                    ├─ 本地图像分析
                    ├─ 手动裁剪与预览
                    └─ 可选 AI 构图与报告翻译
                         ↓
                  完成并归档 → 我的作品 → 摄影洞察
                         ↑                      ↓
                   下次创作 ← 摄影档案中的偏好与练习目标
```

### 草稿与版本

- 导入成功后显示项目名和自动保存状态；尚未保存成功不能显示“已保存”。
- 编辑自动保存到草稿，不要求每次点击“保存记录”。停止连续操作后约一秒尝试保存，是本稿的交互目标而非当前性能承诺。
- 自动保存不锁住拖动。旧保存响应只能确认其对应版本已写入，不能覆盖更新的裁剪、说明或模式；界面区分“已保存”和“有更新待保存”。
- 点击“完成并归档”时提交当前快照，短暂锁定会修改成片的操作，成功后进入作品详情；失败保留草稿并在原位置重试。
- 同一项目再次编辑生成新草稿版本，原已确认版本继续可查看；确认新版本后更新作品的当前成片，不重复增加作品数。
- 归档依赖照片、成片与编辑快照的持久保存完成，不能只把项目指向将于一小时后清理的任务文件。
- AI 报告、翻译和选择说明均可为空，有则保存。AI 未运行或失败不能成为归档失败的原因。
- 下载不要求先运行 AI，也不强制填写备注。未归档草稿可下载当前裁剪；它不因此自动成为正式作品或偏好证据。

### 模块状态互不替代

| 情况 | 页面行为 |
| --- | --- |
| GPU 忙碌、AI 尚未调用 | 本地分析与手动精修照常可用；AI 区显示未运行或排队 |
| AI 返回时用户已继续编辑 | 提示有新建议，放入候选；不覆盖当前画布，用户主动选择才替换 |
| AI 失败 | 只在 AI 区给出原因和重试，保留图像数据与当前手动草稿 |
| DeepSeek 不可用 | AI 报告显示原文；不阻断裁剪、归档或其他图表 |
| EXIF 缺失 | 拍摄参数显示未记录，不猜设备或曝光参数 |
| 服务端断线 | 已加载照片的本地分析与预览保留；云端保存、归档和服务器制品下载明确暂停，不宣称离线已保存 |
| 登录过期 | 暂停受保护操作并引导重新登录，不将旧会话任务交给另一身份 |
| 项目不存在、被删除或无访问权 | 显示不可访问并提供回作品列表；不拿另一张图替代 |
| 临时任务过期但项目已持久保存 | 从项目重新打开，不依赖旧任务链接；AI 重新运行是显式操作 |

独立参考意味着可以分别使用，不意味着必须每张照片运行完所有模块。像素数据、AI 报告和用户备注始终保留来源标识，不能由一句“智能分析”混合代称。

每次 AI 请求绑定当时的照片、用途、目标比例与方向设置。等待期间改了设置，返回结果标为“基于旧设置”，不能直接用旧比例覆盖当前比例；用户可明确恢复原设置后应用，或按新设置重新请求。不同照片的结果不进入当前候选。报告始终指向该次输入而非当前成片；归档后到达的建议也不改写已确认版本，采用时先进入新草稿。

## 图表与照片联动规则

- 工作台统计范围为“原图”或“当前裁剪”，切换后标题与图例同步改变。原图和选区对比统一使用像素比例，避免面积不同导致柱高误导。
- 亮度图点击某个区间后，可开关照片中对应像素的遮罩；同一功能提供键盘可达的区间选择，不只支持悬停。
- 色相图使用带标签的色相条，中性色单列；主色板显示色块、颜色值和占比。不能把黑白图硬解释成红色偏好。
- 亮暗极值仅称“接近纯白或纯黑的像素”，不称曝光错误率。采样计算须标为近似，所有遮罩与辅助线不写入下载成片。
- 照片像素统计不代表相机 RAW 测量，也不自动构成裁剪前后审美排名。清晰度打分、审美雷达和“水平增长率”不在本版。
- 洞察中的每张图同时提供日期范围、样本量、统计对象和“查看相关作品”。EXIF 图另显示有效样本覆盖，缺失样本不计为零。
- 默认按正式作品当前版本统计；同一项目的多次修改不累计。示例档案、真实作品及 Mock AI 记录不能静默混合。
- 时间不足或记录稀少时使用计数、列表和说明，不凭一两次操作画“成长趋势”。趋势图用于时间数据，分类偏好用条形图，不强求每页都有环形图。

来源用两个独立标记表达：照片与项目来源为“用户创作／固定示例”，AI 运行方式为“Venus／Mock（模拟输出）／未运行”。真实照片即使未调用 AI，或只试用了 Mock，像素、用途与真实 EXIF 仍可进入正式作品统计；Mock 生成的方向、报告及其接受记录不进入真实 AI 选择分析。界面不能把“已归档”当作来源，也不能把“未运行 AI”当作无效作品。

## 组件与文案

共享组件包括应用侧栏、顶栏、页面标题、照片卡片、工具标签、图表面板、来源标记、保存状态、空状态与错误恢复区。面板不因换页面就改变边框、圆角、标题字号或按钮样式。

建议统一使用以下文案：

| 语义 | 文案 |
| --- | --- |
| 创作开始 | 新建创作、导入照片 |
| 自动保存 | 正在保存草稿、已保存、有更新待保存、保存失败重试 |
| AI 入口 | 获取 AI 构图参考，不用“生成最佳作品” |
| 档案确认 | 完成并归档；已有作品编辑时为保存新版本 |
| 图像统计 | 图像分析、本地像素统计、当前裁剪 |
| 数据来源 | 你的创作、示例档案、固定使用样例、Mock AI 参考 |
| 偏好采用 | 设为常用、忽略此建议、恢复默认 |
| 清理说明 | 分别说明临时任务、草稿、已归档作品，不统一写“一小时删除” |

## 设计验收清单

### 视觉与宽屏

- [ ] 1440 × 900 下，展示首页、创作概览、工作台在品牌、底色、字级、图标和主要操作上连续一致。
- [ ] 1366 × 768 下，工作台首屏看见照片主体和核心编辑按钮；无先经过长工具列表才能看到图片的问题。
- [ ] 1920 × 1080 下，内容有上限，不把表单、报告和图表拉成难读的全屏长行。
- [ ] 工作台默认单主画布、工具按需展开；对照和完整报告仍能找到，没有因简化而删除关键功能。
- [ ] 状态、数据来源和图表图例不依靠颜色单独表达；示例与真实内容在列表、详情和统计页均可识别。

### 交互与可访问性

- [ ] 五个主入口全程可达，返回保留列表条件，深链接和刷新不会静默清空项目。
- [ ] 所有图标操作有名称；表单有标签；密码允许粘贴和密码管理器。
- [ ] 正文文字对比至少 4.5:1，关键非文字标记至少 3:1；照片上的文字有独立衬底。
- [ ] 鼠标、键盘均可切换工具、调整裁剪、选择统计范围和查看图表数据；拖动有按钮替代。
- [ ] 核心操作区沿用至少 44 px 的舒适点击高度；焦点不会被固定头部或弹层遮住。
- [ ] 200% 页面缩放不丢失必要操作，减少动态效果时所有状态仍可读；这些是后续实现的验收条件，不是本稿已运行的测试结果。

### 数据与错误恢复

- [ ] AI 关闭或失败时，可以独立完成本地图像分析、手动精修与在线归档；API 离线时不伪装保存成功。
- [ ] 自动保存、AI 返回与归档不会用旧响应覆盖新编辑。
- [ ] 示例、草稿和正式作品的统计口径一致可追溯；删除、修改当前版本后统计相应更新。
- [ ] 作品恢复依赖持久项目资源，不依赖旧临时任务文件；无照片时不会显示无法兑现的“继续编辑”。
- [ ] 共享演示账号不展示私人空间的误导文案；演示重置不能通过普通访客无确认地清空共同作品。
