# 宽屏摄影工作室 V2：第一阶段交付记录

日期：2026-10-17。范围：按已确认设计搭建五页与统一视觉，不提前接入账号、持久作品或图像统计。

## 本阶段实现

- 展示首页 `/` 保留摄影大图、上传、场景卡和使用指南，增加“进入工作室”入口；真实上传和固定样例均进入工作台。
- 工作室侧栏固定五页：创作概览、构图工作台、我的作品、摄影洞察、摄影档案。支持 `/studio`、五个 `/studio/*` 一级地址、前进后退、直接打开与刷新；未知地址有返回出口，不伪装打开项目。
- 首页与应用共用暖白、森林绿、字体和线性图标；216 px 侧栏、64 px 顶栏，窄屏仍能操作，没有新增独立移动流程。
- 工作台默认单画布，提供裁剪、成片预览、对照三个视图。320 px 右侧工具区容纳候选与折叠报告，尺寸、辅助线、精细调整和可选选择依据继续可用。
- 五页间切换保留当前上传选择、裁剪坐标、选中候选、备注和工作台视图；分析完成不会自动抢走用户正在查看的其他页面。返回展示首页仍保留 App 中当前裁剪数据，但局部视图和未提交上传表单不承诺保留。
- 切换新照片或固定样例时保护未保存调整；离开正在分析的任务有明确确认。未应用的裁剪、选择或备注存在时，刷新/关页触发浏览器标准离开提醒。
- 当前会话可在概览和作品页找到，但不冒充已归档作品。没有账号、作品或指标时展示有说明、有下一步的状态，不使用虚构 KPI、假图表或模拟登录。

## 当前数据边界

现有真实上传仍走 API、worker 和临时任务；任务文件继续按一小时规则清理。界面中的“确认当前方案／应用裁剪”只更新该任务，不等于长期归档、自动草稿或版本历史。

固定使用样例不调用 API 或模型，在浏览器生成裁剪下载；Mock 是实际后端链路中的模拟模型输出，两者均保留来源说明。真实 Venus 的质量不在本轮测试结论内。

图像分析页签目前只呈现已有尺寸、比例、保留面积；直方图、色彩分析及 EXIF 读取明确标为尚未接入。作品、洞察、档案的当前说明不代表后端存储和账号已完成。

原翻译能力和降级链路未改动。本轮服务测试关闭外部翻译，不使用私有密钥或真实 GPU。

## 验证

- 前端单元及静态结构测试：107 项通过；新增导航、五页、工作台和来源边界用例。
- TypeScript 检查、Vite 生产构建及 Ruff 检查通过；Python 95 项回归通过，保留依赖库弃用警告。
- Edge 浏览器检查：1366 × 768、1440 × 900、1920 × 1080、1024 × 900、768 × 1024、375 × 812 六种尺寸；首页、五页与样例三个视图无横向溢出。
- 验证浏览器前进后退、直接进入/刷新、键盘页签与裁剪、切页保留调整、隐藏上传区不接收其他页的粘贴、样例不调用后端。
- 最终浏览器记录共 65 组检查、零页面运行异常；补验拖动时后退导致画布隐藏的编辑锁定，以及拒绝替换照片/样例后保留当前调整。
- 样例 PNG 下载及真实 HTTP Mock worker 的 JPEG 下载均可解码；商品主图下载比例符合 4:5。AI 完成时不会把作品页强制切回工作台。
- 已人工检查主要截图，包含概览、宽屏工作台、Mock 照片及窄屏退化布局。自动布局、减少动态效果和增大根字号的检查不等于完整辅助技术审计或真实浏览器 200% 缩放认证。

浏览器脚本、截图、下载文件与结果位于被忽略的 `var/desktop-workspace-v2-review/`；独立四页检查另在 `var/workspace-v2-pages/`。这些运行产物不进入 Git。代码和文档尚未因本记录而提交或推送。
