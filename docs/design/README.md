# Design documents

Store the approved design system, user flows, wireframes, component specifications, content rules, accessibility requirements, and visual QA evidence here.

When frontend design begins, use `$ui-ux-pro-max` to generate a project-level design system and keep its master output under this directory or link to the generated `design-system/` source of truth.
