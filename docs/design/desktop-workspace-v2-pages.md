# 桌面摄影工作室 V2：五页功能与布局附录

日期：2026-10-17。状态：方案已确认，账号、作品保存、浏览器图像分析、归档洞察与主动保存偏好已分阶段接入；本文仍描述完整目标。当前范围见[第四阶段交付记录](desktop-workspace-v2-phase-4.md)，图表见[第三阶段](desktop-workspace-v2-phase-3.md)，保存边界见[第二阶段](desktop-workspace-v2-phase-2.md)及[产品边界](../product/photography-workspace-v2.md)。

本附录配合[桌面工作台主设计](desktop-workspace-v2.md)与[摄影工作室产品方案](../product/photography-workspace-v2.md)阅读。
主设计确定整体视觉与信息层级，产品方案确定能力、身份和保存边界；本文说明每页具体如何使用。

## 共同桌面壳与阅读规则

- 主设计尺寸为 1440 × 900；同时验收 1366 × 768 与 1920 × 1080。
- 左侧栏固定 216 px，顶栏 64 px，内容区内边距 32 px，主要间距 24 px。
- 侧栏仅五项：创作概览、构图工作台、我的作品、摄影洞察、摄影档案。
- 顶栏放页面位置、当前项目名称与真实保存状态；账户或档案设置放右端。
- 当前共享访问码只代表进入演示服务的权限，不能标识某一个用户。
- 宽屏主内容保持同一外框；工作台右工具面板 320 px，不把手机三列布局直接拉宽。
- 暖白底 `#F6F5F1`、卡面 `#FFFEFA`、森林绿 `#275C4C`、选中面 `#E5ECDF`。
- 深色 `#202622` 只用于照片舞台；工具、报告、导航继续使用浅色面。
- 每个区域最多一层卡面；用标题、分隔线和间距区分内部内容，不层层套卡。
- 页面标题表达任务，主按钮表达下一步结果；不以重复的宣传标题占据工作区。
- 当前窄屏流程保留；本轮不新增移动专属页面、底栏或独立功能分支。
- 1366 px 下工作台主画布约有 742 px 宽，1440 px 下约 816 px，1920 px 下约 1296 px。
- 画布按剩余视口高度适配照片，工具面板可独立滚动；首屏看见整张待编辑照片与主要操作。
- 按钮有文字名称，图标不单独承担解释；焦点可见，折叠、切换和图表筛选可用键盘操作。
- 照片持久副本由产品方案单独定义；本附录不把原任务的一小时临时目录延长为作品库。
- 项目恢复读取持久照片资产及编辑快照；副本缺失时提示重新选择照片，不拼接过期任务路径。
- 每张图表标明时间范围、样本数量与来源；分别标记项目来源（用户创作／固定示例）和 AI 运行方式（Venus／Mock／未运行），按主设计的统计规则处理。
- 无可用 GPU 时，本地图像分析、手动精修、草稿和作品管理仍可工作。

## 1. 创作概览

### 目的与首屏主次

帮助用户继续创作，或从一项明确用途开始；它是工作入口，不是数据大屏。
首屏主要区域为最近项目，主要操作为“导入照片”；真实小统计与练习提示排在其次。
不展示虚构用户数量、累计节省时间、模型准确率或演示数据填充的增长曲线。

### 低保真布局

```text
+---------------+----------------------------------------------------------+
| SmartCrop     | 创作概览                                  [摄影档案]     |
|               +----------------------------------------------------------+
| 创作概览      | 欢迎回来                          [导入照片，开始创作]   |
| 构图工作台    | 正式作品 12    本月完成 5    待整理草稿 2                 |
| 我的作品      |                                                          |
| 摄影洞察      | 最近项目                          [查看全部作品]         |
| 摄影档案      | [照片 / 项目名 / 草稿 / 继续] [照片 / 已归档 / 查看]      |
|               |                                                          |
|               | 常用创作设置                   本阶段关注                 |
|               | 旅行分享 / 4:5 / 环境叙事      拍摄前检查画面边缘          |
|               | [沿用设置创建项目]             [查看练习清单]             |
+---------------+----------------------------------------------------------+
```

### 功能与操作结果

- “导入照片”建立新项目并进入构图工作台；导入完成后开始保存草稿，不自动启动 GPU。
- 点击最近草稿，恢复照片副本、当前视图、裁剪参数及未归档版本。
- 点击已归档项目先打开作品详情；“继续编辑”创建同项目的草稿修订，不立即改写正式成片。
- “沿用设置创建项目”只带入用途、比例和用户明确保存的偏好，仍由用户选择新照片。
- “查看练习清单”进入摄影档案的练习子区，不新增第六个顶级页面。
- 统计数字可点击：正式作品进入归档筛选，本月完成进入日期筛选，草稿进入草稿筛选。

### 数据来源与状态

- 最近项目来自当前档案的项目索引；正式作品按项目计数，不累计同项目版本和候选。
- 常用设置优先使用主动设置；历史建议明确标注“根据最近 N 次主动选择建议”，允许忽略。
- 首次进入显示导入入口和独立的“查看使用样例”；样例不混入最近项目和个人统计。
- 加载时保留区块尺寸，显示少量项目占位；计数尚未得到时显示“读取中”，不先显示 0。
- 项目索引读取失败显示重试与错误说明；照片副本缺失保留项目标题和参数，不画假缩略图。

### 验收

- 三种桌面尺寸首屏均能看见导入、至少一条最近项目和真实保存状态。
- 统计点击后筛选结果与数字一致；只有样例时仍显示“尚无正式作品”。
- 继续草稿恢复当前编辑状态，不因旧 AI 任务失效而丢失已有持久照片。

## 2. 构图工作台

### 目的与首屏主次

让用户观察照片、获得参考并完成编辑；照片舞台是第一视觉中心，右面板解释当前所见。
主要交付操作为“完成并归档”；下载与 AI 分析为独立动作，不以调用模型作为进入编辑的前提。
用途采用标题旁的简短设置入口，避免把长表单放在照片上方。

### 低保真布局

```text
+---------------+----------------------------------------------------------+
| 固定侧栏      | 构图工作台 / 山间旅行                      草稿已保存    |
|               +----------------------------------------------------------+
|               | 旅行分享 · 4:5        [AI 构图] [下载] [完成并归档]      |
|               |                                                          |
|               | [裁剪 | 预览 | 对照]           | 图像分析 / AI参考 / 拍摄参数 |
|               | +---------------------------+ |                          |
|               | |                           | | 亮度 / RGB 直方图        |
|               | |       照片主画布          | | 色相与中性色             |
|               | |      拖动与精修操作       | | 主色板 4-6 色            |
|               | |                           | | [亮区遮罩] [暗区遮罩]    |
|               | +---------------------------+ |                          |
|               | [位置微调] [范围] [辅助线]    | 当前来源 / 参数说明      |
|               | 当前：环境叙事 [展开其他方向] |                          |
+---------------+----------------------------------------------------------+
```

### 功能与操作结果

- 导入后即可查看像素分析和编辑；先保存一份项目照片副本，随后变更自动保存为草稿快照。
- “裁剪”显示可操作取景框；“预览”显示当前草稿成片；“对照”显示同一照片的原图与当前成片。
- 三种视图共享裁剪状态；辅助线和亮暗遮罩只用于观察，不写入下载图。
- 画布边提供比例、位置、范围、重置及辅助线，默认只展示常用项，精细参数按需展开。
- 候选条只显示当前方向；展开后查看其他方向，选择后折叠并将键盘焦点送回展开入口。
- 点击“AI 构图”提交当前照片与偏好，显示当前任务状态；排队或运行中仍可本地编辑。
- AI 返回时若草稿已改变，提示“参考已生成”，作为可选候选保留，不自动覆盖手动版本。
- 用途或比例已改变时，旧参考标明其原设置，不直接套用；恢复原设置后应用或按新设置重新请求。照片不一致的结果不混入当前项目，归档后迟到的结果不修改正式成片。
- 用户主动应用参考才改变裁剪框；手动版本仍可恢复，AI 报告始终注明对应的初始参考范围。
- “完成并归档”固定当前版本与用途信息，更新该项目的正式作品入口；草稿保存不等于归档。
- 再次编辑归档项目后，按钮改为“保存新版本”，明确更新当前正式成片并保留旧版，同项目不新增第二件作品。

### 右面板的数据来源

- “图像分析”含亮度/RGB 直方图、色相条图及独立中性色、4-6 色主色板和亮暗遮罩。
- 这些数据由照片像素计算，标注分析对象为原图或当前裁剪，并提供一致的对象切换。
- 点击亮暗区间在照片上标出对应区域；“高亮像素占比”不写成“曝光错误率”。
- “AI 参考”展示独立任务状态、当前方向和对应报告；失败时可重连或重试，原草稿保持可用。
- “拍摄参数”只展示实际读取到的 EXIF 字段，如拍摄时间、机型、焦距、光圈、快门和 ISO。
- EXIF 缺失显示“照片未包含此参数”，不从照片内容猜测；不展示美学分、清晰度分或优劣排名。

### 空、加载、错误状态与验收

- 未导入显示画布内导入入口；像素分析尚未完成时仅面板占位，不遮挡已显示照片。
- 自动保存失败持续显示“尚未保存”与重试，归档不能伪报成功；AI 连接失败不禁用本地工具。
- 三种视图及切换页签不重置编辑；无 GPU 可完成像素分析、精修、草稿保存和归档。
- AI 在本地编辑后返回不会覆盖草稿；已过期任务不阻止用户继续保存或下载当前成片。
- 1366 × 768 首屏仍以照片为主，不要求先滚过长表单才能开始操作。

## 3. 我的作品

### 目的与首屏主次

集中查找、恢复和管理项目，区分工作中的草稿与已完成作品。
首屏主要为照片与项目状态；筛选和排序为辅助，不把每一次模型请求都显示为独立作品。

### 低保真布局

```text
+---------------+----------------------------------------------------------+
| 固定侧栏      | 我的作品                                  [导入照片]     |
|               +----------------------------------------------------------+
|               | [全部项目 | 已归档 | 草稿]    [搜索项目名或个人标签]      |
|               | 日期 [最近30天] 用途 [全部] 来源 [用户创作] [重置筛选]    |
|               |                                                          |
|               | [照片 A]             [照片 B]            [照片 C]        |
|               | 山间旅行 / 已归档    咖啡桌面 / 草稿    海边日落 / 已归档 |
|               | 4:5 · 10月17日       自由 · 尚未归档     16:9 · 10月15日  |
|               |                                                          |
|               | 作品详情抽屉：成片 / 用途 / 版本 / 主动选择 / 个人笔记    |
|               | [继续编辑] [下载归档成片] [管理项目]                      |
+---------------+----------------------------------------------------------+
```

### 功能与操作结果

- 已归档卡使用正式成片缩略图，草稿卡使用当前编辑预览；文本同时标明状态，不只靠颜色。
- 点卡打开可直接访问的详情抽屉，查看用途、版本时间、裁剪尺寸、选择来源及用户记录的关注点；直接访问详情地址也能加载同一项目。
- “继续编辑”从项目持久照片及指定版本恢复，不读取已清理的模型输入或制品链接。
- “下载归档成片”下载已归档版本；存在更新草稿时明确提示两者不同，不悄悄下载草稿。
- 版本列表用于回看和恢复；选旧版本进入草稿，只有再次归档才替换正式版本。
- 项目改名和个人标签修改立即更新索引；是否改名不影响模型输出、成片或作品计数。
- 删除前列明将移除的项目、照片副本、版本及账号记录；其他项目仍引用的照片不连带删除。共享演示账号下同时提示会影响其他参与者，并要求明确确认。

### 数据来源与状态

- 项目索引、版本快照和持久照片资产关联展示；缩略图不是过期临时任务路径的替身。
- 日期筛选默认使用归档或最近编辑时间，并明确字段；拍摄日期只有 EXIF 存在时可另选。
- 演示来源独立筛选，不能计入正式作品；没有缩略图时显示中性占位和缺失原因。
- 空库显示“还没有作品”和导入入口；筛选无结果时保留条件并提供“清空筛选”。
- 加载更多时保留当前列表与位置；读取失败只影响相应项目，不以整页空白替代已有记录。
- 照片副本不可用时详情仍可看参数与笔记，允许重新选择同一照片并校验文件是否匹配；不匹配的照片只能另建项目，不沿用旧图表与报告，不声称可以恢复已删除原图。

### 验收

- 同项目连续编辑三次、归档两次，正式作品仍计一件，版本可区分且可恢复。
- 原模型任务过期后，持久副本存在的项目仍能恢复编辑；缺失副本时有明确操作出口。
- 用途、日期和来源筛选可组合；从洞察图表跳入的筛选条件清楚可见。

## 4. 摄影洞察

### 目的与首屏主次

帮助用户理解自己的用途、主动选择和拍摄记录，给下一次创作提供依据。
首屏先交代统计范围，再展示少量可操作结论；不以图表数量、曲线涨幅或评分营造进步感。

### 低保真布局

```text
+---------------+----------------------------------------------------------+
| 固定侧栏      | 摄影洞察                                                |
|               +----------------------------------------------------------+
|               | [最近30天] [全部用途] [用户创作]       已归档作品 N 件   |
|               | 主动选择记录 M 次 / EXIF 可用 K 件 / 不含演示来源         |
|               |                                                          |
|               | 主要用途条图                  主动构图方向条图           |
|               | [社交封面：点击查看作品]      [环境叙事：点击查看作品]   |
|               |                                                          |
|               | 用户确认的关注点              拍摄参数分布               |
|               | 边缘干扰 / 留白 / 主体        ISO / 焦距 / 光圈          |
|               |                                                          |
|               | 色彩与明暗观察：色系作品条图 / 成片亮度分布              |
|               | [暖色作品缩略图] [中性色作品缩略图] [查看相关作品]       |
|               |                                                          |
|               | 建议：是否把常用比例设为默认？ [查看依据] [前往设置]     |
+---------------+----------------------------------------------------------+
```

### 功能与操作结果

- 日期、用途和来源共同限定所有图表，切换范围后标题、分母与记录列表一起更新。
- “主要用途”展示正式作品的实际用途；点击一条进入我的作品并带上相同时间和用途筛选。
- “主动构图方向”仅计用户明确选用的方向，单列样本数；默认方案的下载或归档不等同主动偏爱。
- “关注点”仅统计用户确认的标签；未经确认的 AI 问题描述不自动变成用户的摄影弱点。
- EXIF 参数按实际可用作品展示，并标注覆盖数量；焦距、ISO 与光圈各有自己的有效样本数。
- 同用途的裁剪保留面积可作补充观察，只解释裁剪习惯，不写成审美改善或拍摄水平变化。
- “色彩与明暗”放在上述摘要下方：按当前成片的主色系展示作品数量条图，中性色独立成组；点击分组查看对应照片。主色依据同一套像素分析，不把暖色作品多解释成性格或审美等级。
- 明暗区用归一化亮度分布，并显示单张成片的小图；汇总时每件作品权重相同，不让高分辨率照片占据更大权重。默认只看成片，原图对比在工作台展开，不生成“优化率”。
- 每个建议先提供“查看依据”，再允许进入摄影档案设置；不自动改写下一次创作参数。

### 数据来源与状态

- 默认只用正式归档项目的当前版本；同项目旧版本、草稿和三个候选不重复累加。
- EXIF 使用持久照片中实际存在的字段，不把上传时间冒充拍摄时间，不从像素猜设备。
- 每图明确“作品数”或“主动选择次数”；同作品的多个关注点可多选，不能误报为互斥占比。
- 没有正式作品时显示统计如何产生及创作入口，不用固定样例填满图表。
- 样本少只描述已有数量，不输出趋势判断；没有 EXIF 时参数区说明缺失而非绘制 0 分布。
- 单一区块计算失败允许局部重试；删除或更新归档后重新计算，不保留脱离来源的旧画像。

### 验收

- 任意图表均能点回支持其数字的作品集合；分母、日期和来源对得上。
- 只下载默认方案的用户不会被归类为偏爱该方向；删除项目会同步更新相关统计。
- 混有用户照片、Mock 与固定样例时，不混入固定历史或 Mock 选择证据；用户照片的客观统计不因没用真实模型而消失，无 EXIF 不出现推测参数。

## 5. 摄影档案

### 目的与首屏主次

让用户明确管理“下次希望怎样创作”，并解释哪些设置来自主动选择、哪些只是历史建议。
首屏是可编辑的创作默认值，不是自动生成的人格介绍；练习清单属于本页子区。

### 低保真布局

```text
+---------------+----------------------------------------------------------+
| 固定侧栏      | 摄影档案                                                |
|               +----------------------------------------------------------+
|               | [创作偏好 | 练习清单 | 保存与数据]                       |
|               |                                                          |
|               | 常用用途 [旅行分享]   默认比例 [4:5]                     |
|               | 常用方向 [环境叙事]   当前来源：用户主动设置              |
|               | [保存，下次创作使用]                                    |
|               |                                                          |
|               | 历史建议：最近 M 次主动选择中，环境叙事占 X 次            |
|               | [查看作品依据] [采用此设置] [忽略]                       |
|               |                                                          |
|               | 练习清单：检查边缘 [下次提醒] [完成一次练习]             |
+---------------+----------------------------------------------------------+
```

### 功能与操作结果

- 用户可设置常用用途、比例、构图方向和希望保留的信息；保存后明确提示将影响下一次新项目。
- 当前项目不被新默认值直接重写；需要采用时在工作台明确选择，已有裁剪版本保持可恢复。
- 主动设置优先级最高；历史建议只能经“采用此设置”生效，采用后也能修改或恢复默认。
- 每项偏好显示来源：主动设置、用户主动选择的历史，或产品初始默认；不把默认沿用当偏爱。
- 练习从用户认可的关注点建立，例如“先检查边缘”；用户决定是否在下次创作提醒。
- “完成一次练习”只记录用户自报完成，不让模型给练习打分，也不据此宣称照片变好。
- 页首显示演示身份与“共用档案”说明；设备信息仅来自用户主动填写或已有 EXIF，不推测缺失设备。
- 保存与数据子区说明服务端账号档案、持久照片副本及临时模型任务的不同保存边界，不把它们称作浏览器本机存储。
- 副本保存、迁移或清理的具体选择服从产品方案；共享访问码不能替代账号会话，演示参与者会共用同一份档案。

### 数据来源、状态与验收

- 首次使用显示可修改的产品默认值，标明尚无历史依据，不生成虚构画像。
- 偏好加载时不把空值误写回档案；保存失败保留表单与重试入口，不先显示已生效。
- 画像只涉及创作偏好与目标，不推断人格、年龄、健康、情绪或其他敏感属性。
- 仅下载默认成片不会增加主动偏好次数；手动设置后下一项目的表单与实际提示词保持一致。
- 练习仅为本页子区，用户可暂停或删除；删除依据作品后，历史建议同步更新。
- 三种桌面尺寸能清楚区分已生效设置、未保存修改和待采用建议。

## 跨页闭环验收样例

1. 小林导入旅行照，无 GPU 时完成像素分析和手动裁剪，草稿显示真实保存状态。
2. 后续获得 AI 参考时，已编辑草稿不被覆盖；小林主动选用环境叙事并归档为一件作品。
3. 我的作品能在临时任务过期后从持久照片副本恢复；新修订不会重复增加作品数。
4. 洞察只累计正式项目及主动选择，图表可点回这件作品，不声称审美提高。
5. 小林将相关比例设为常用，并加入边缘检查练习；下次创作可见这些设置且仍可修改。

以上完整页面行为分阶段实现。第一阶段只建立导航、页面结构和临时工作台视觉，不代表当前仓库已具有项目持久化、作品库、统计或偏好记忆。
