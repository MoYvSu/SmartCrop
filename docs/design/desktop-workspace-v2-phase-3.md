# 宽屏摄影工作室 V2：第三阶段图像分析与摄影洞察

日期：2026-10-17。范围：浏览器端描述性像素分析、已归档作品的真实统计。不引入模型评价、EXIF 提取或个人画像。

本记录接续[第二阶段](desktop-workspace-v2-phase-2.md)的账号与作品保存；算法和数据边界见 [ADR-0011](../decisions/0011-browser-pixel-analysis-and-archive-statistics.md)。前两阶段的交付记录保留为当时状态，本记录覆盖其中“图像分析与洞察尚未接入”的限制。

## 工作台：看懂当前画面

右侧默认打开“图像分析”，提供“当前裁剪／完整原图”切换。主画布、辅助线、精细裁剪、可选 AI 与归档下载沿用前两阶段，不把分析变成额外门槛。

- 亮度：32 个区间的分布、0—255 平均参考值，以及近黑／近白像素占比。
- 色相：12 个 30° 区间；单独显示有彩占比，灰阶、低饱和与极暗像素不强归色相。
- 主色：最多五种近似代表色，显示 HEX、RGB 及占比，包含中性色；近色合并，不强凑五色。
- 切换范围或修改取景后，先移除旧范围的结果，停顿约 280 毫秒再计算，避免旧图表冒充新测量。
- 全透明范围明确没有可统计的可见像素，不伪造成全黑；读取失败有错误与重试，仍可裁剪、保存和下载。
- 固定样例也可观察真实像素，但明确不进入账号作品统计。

图表使用暖白与森林绿，没有装饰性随机曲线。各分布提供可键盘展开的数据表，主色配有文字和数值，不靠色块独自表达。宽屏工具区独立滚动，标签固定并预留焦点空间；窄屏回到普通文档流。

## 摄影洞察：先有作品，再谈统计

页面读取账号已保存项目，只统计每项目**最新归档版本一次**。草稿、固定使用样例和旧临时任务不计入；已有新草稿的作品明确提示“有新草稿，未计入本次统计”。

- 范围：全部、最近 30 天、最近 90 天，按归档时间筛选，不按最近改草稿的时间筛选。
- 覆盖：已归档数量、像素读取成功数、有可见像素数及失败数；逐张处理，失败作品不混成黑图或假零。
- 明暗与配色：复用亮度、色相与主色图表。各可见作品等权，不让大尺寸图或多次归档重复加权。
- 用途与取景：归档成片横幅／竖幅／方形分布、保存的发布模板及平均保留面积；缺失数据标明未记录。
- 来源：参与作品逐项显示固定归档图、版本、尺寸及读取状态；“继续编辑”打开真实项目。
- 空库、无匹配范围、列表失败、部分像素失败与全透明分别呈现，不以示例统计填充。

用途只代表保存时选择的模板，不证明实际发布。保留面积描述裁剪幅度，不表示构图好坏。当前共用账号不能生成某一个人的摄影画像，也不从默认接受或下载行为推断审美偏好。

## 计算与隐私

分析使用浏览器保存图像副本的 sRGB 像素：基础图像最长边 1280，当前范围采样最长边 384，不主动放大小图。数学计算优先在浏览器后台线程运行；不支持时对小样本受控回退。具体权重、阈值、色相分母及聚类近似见 ADR。

这不是设备原始文件、RAW 曝光诊断或专业色彩测量。原有保存链路会规范化并重新编码图像；不透明图转为 JPEG，边界和颜色可能有微小变化。图表基于实际保存副本，不能用测试输入文件的精确 RGB 字节要求重编码后完全相同。

新增分析不调用模型，不向第三方发送图像或分析结果，不将像素结果写入训练集。照片的原有服务器保存仍然存在；“浏览器计算”不代表照片从不上传。分析缓存仅在内存中，刷新可重算；退出、账号失效或删除作品时取消并清理，旧响应不能回填。

## 验证

- 前端 238 项测试通过，TypeScript 检查、Vite 生产构建通过；独立图像分析 Worker 正常打包。新增纯算法、采样／取消／超时、冻结快照汇总与界面状态用例。
- Python 156 项通过、2 项平台条件跳过；Ruff 与差异空白检查通过。后端没有新增图像计算或模型调用接口，旧保存与翻译链路继续回归。
- Edge 实际浏览器共 34 组功能／布局检查，零页面运行异常。实际启动分析 Worker，并另验无 Worker 时的小样本回退；本轮图像分析与洞察请求记录中模型调用为零。
- 红蓝测试图验证原图／当前裁剪分布、代表色和移动后更新；切换范围立即不再显示旧结果。灰阶亮度正确且不生成色相，全透明明确没有可见统计。数值对实际重编码图像留容差，而非错误要求 JPEG 仍有输入 PNG 的精确色值。
- 归档统计验证草稿不计入、每项目最新版本一次、刷新恢复、新归档更新但作品数不增加、按归档时间筛选、删除后移除贡献；刻意使一张成片读取失败，其他真实结果保留，重试后恢复。
- 验证真实空库不造图、固定样例不发上传／分析请求、不进入洞察。部分失败与透明作品的计数各自保留，不把它们伪装成黑图或丢失项目。
- 1366 × 768、1440 × 900、1920 × 1080、1024 × 900、768 × 1024、375 × 812 均检查洞察与工作台，无横向溢出、重复 ID 或重复可见主区；宽屏主照片首屏可见，工具区滚动高度受限。
- 数值表可用键盘展开，焦点位于固定工具标签下方；窄屏、减少动态效果和增大根字号检查通过。这不等于完整辅助技术、200% 浏览器缩放或跨浏览器认证。

运行脚本、截图、临时测试照片与浏览器记录保存在忽略目录 `var/desktop-workspace-v2-phase-3-review/`，不进入 Git。验收创建的红蓝、灰阶、透明与未归档项目均是明确测试夹具，结束后仅清理这些项目，原有作品未改动。

## 下一步边界

摄影偏好编辑、设备档案、EXIF 白名单、跨设备缓存、全分辨率专业分析及生产级性能／无障碍认证未在本轮实现。原有 AI 参考和可选翻译继续独立存在，不恢复终稿复评、复拍排名或主动训练功能。代码与文档未因本次实施而提交或推送。
