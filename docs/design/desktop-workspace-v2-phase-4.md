# 宽屏摄影工作室 V2：第四阶段创作偏好与色彩气质

日期：2026-10-17。接续[第三阶段](desktop-workspace-v2-phase-3.md)，覆盖旧记录中“摄影偏好尚未接入”的限制。

## 摄影档案

右侧“创作偏好”提供常用用途、裁剪比例与模板、自定义宽高和四种辅助线；可以全部关闭辅助线。点击“保存创作偏好”才更新账号默认设置，成功提示下次新建自动采用、已有作品不变。

输入具备明确标签、键盘焦点和加载／保存反馈。无效自定义比例保留输入并将焦点移回字段；读取失败可重试，保存冲突保留输入，需明确重新载入再调整。表单跨页、前进／后退保留未保存修改；刷新或退出时提醒。暖白、森林绿、卡片与控件沿用现有工作室风格，窄屏辅助线选项改为单列。

演示账号的偏好与作品一样共用，登录后能恢复，不是每位访客独立的私人档案。不增加注册、找回密码或虚构设备信息。

## 新建与继续作品

新建读取账号默认用途、画幅与辅助线，用户可为本次照片自行调整。导入时形成作品独立快照；继续旧作品使用旧作品自己的设置，不跟随之后的账号偏好变化。

辅助线修改进入草稿自动保存，刷新、重新登录和继续编辑后恢复；归档版本也保留这一编辑状态，但照片像素不包含线条。固定使用样例继续使用固定初始设置，不冒充账号保存记录。

访客从展示首页导入、随后登录时：未改过用途／画幅则采用账号默认值；主动选择过的本次设置优先保留。偏好读取失败不伪装成功，也不自动发起模型推理。

## 主色描述与文案

摄影洞察的真实作品集主色卡显示“色彩气质”，根据占比最大色块选择预设描述，例如“黑色，深邃而沉稳”“蓝色，澄澈而宁静”“棕色，温润而质朴”。无可见像素或无色板时不编造描述，不将文案当成人格判断。

删除聚类、近色合并、不强凑五色等面向实现的说明，改为简短的观察与使用提示。错误、空状态、最新归档范围及共享账号说明仍保留。算法口径继续记录在 [ADR-0011](../decisions/0011-browser-pixel-analysis-and-archive-statistics.md)，偏好与快照语义见 [ADR-0012](../decisions/0012-account-defaults-and-project-guide-snapshots.md)。

## 摄影档案身份卡收尾

左侧从单色说明卡调整为摄影手账式名片：复用已有山间湖泊素材作为明确标注的灵感封面，搭配取景框、光圈头像和共用空间标签；展示真实已归档／草稿数量、当前创作起点及作品／洞察快捷入口。右侧偏好表单不变。

数量仅使用已成功读取的账号记录，加载或错误不展示虚假零值，固定样例不计入。创作起点只读取服务端当前偏好，不提前展示表单草稿；版本 1 标为初始设置，主动保存后才标为已保存偏好。保留共用账号说明，不增加职业等级、成就或用户资历。
