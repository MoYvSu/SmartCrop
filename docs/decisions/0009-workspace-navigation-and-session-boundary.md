# ADR-0009：五页导航与临时编辑会话分离

状态：Accepted。日期：2026-10-17。

## 背景

第一阶段需要把单页裁剪流程放入五页摄影工作室，用户切换导航时不能丢失编辑或被异步分析结果强制带回工作台。现有任务只有一小时保留期，本阶段不能将它包装成长期作品。

## 决策

- 使用原生浏览器地址历史与 React 的外部状态订阅提供五个一级地址，不新增路由依赖。正常链接支持新标签页，前进后退通过浏览器历史恢复位置；未知及未实现的项目详情地址显示明确出口。
- `App` 继续拥有当前图片、请求、裁剪和选择状态；导航不调用清空或取消操作。工作台在五页之间隐藏而非销毁，保留视图和尚未提交的上传选择；隐藏时不响应图片粘贴。
- 请求代次与取消控制继续拒绝旧响应；分析结束只更新会话数据，不改变当前页面。切换页面移动焦点到可见主内容，隐藏工作台使用独立标识，避免多个 `main-content` 目标。
- 不将照片、裁剪、伪账号或作品索引写入浏览器长期存储。现有访问码的会话存储不因此成为账号认证。
- 暂不实现登录、项目深链接、自动草稿、作品归档、统计或偏好保存。后续持久项目须提供新的服务端归属、资源和生命周期，不能依赖临时制品链接。

## 替代方案与取舍

单纯用内存标签切页无法支持刷新和地址分享；本轮未采用。完整路由库提供嵌套路由和拦截等能力，但目前只有五个平级入口，因此先采用小范围地址模块；新增登录、项目路由时应重新评估，不能继续无限扩展手写路由。

保留隐藏编辑器占用少量内存，换取状态连续性；退出页面或刷新仍会丢失本轮会话，界面明确说明，不承诺离线持久化。只对未应用调整设置离开提醒，不把提醒等同于数据已保存。

## 验证依据

导航模块及页面/工作台静态测试、六尺寸浏览器导航与状态保留、隐藏粘贴保护、真实 Mock 下载链路。详细范围和证据见[第一阶段交付记录](../design/desktop-workspace-v2-phase-1.md)。
