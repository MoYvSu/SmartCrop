# ADR-0012：账号创作偏好与作品辅助线快照

状态：已实施。日期：2026-10-17。

## 背景

摄影档案需要保存常用用途、裁剪比例与辅助线，使下一次创作少一些重复设置。偏好属于共享演示账号，不能只存在当前浏览器，也不能修改已经保存的作品。主色气质采用固定文案，不额外请求模型。

## 决策

- 新增账号级 `account_preferences` SQLite 表，保存 `revision / intent / guides`，复用现有身份、同源与 CSRF 校验。初始读取不落库，返回版本 1；首次保存为版本 2。
- `GET /v1/preferences` 读取；`PUT` 完整保存，要求上次读取的版本。事务内比较版本，冲突返回 409，不静默覆盖其他页面的新设置。
- `intent` 复用现有场景／发布模板／比例契约，不增加互相矛盾的模板和比例组合。自定义比例沿用整数 1–100、宽高比 1:10–10:1 的约束。旧的无模板画幅原样保留。
- 辅助线支持三分、中心、对角和安全区，可组合或全部关闭，拒绝重复与未知项。导出照片不绘制辅助线。
- 创建作品时捕获账号默认设置；显式传入的本次用途／比例优先。辅助线保存在作品草稿和归档版本中，之后修改偏好不追溯改动已有作品。旧作品缺少辅助线字段时固定回退三分线，而非读取最新账号默认值。
- 前端登录后读取偏好，新建时重新读取；未完成或读取失败时给出状态和重试。用户开始手动调整后，后台读取不覆盖本次选择。
- 摄影档案的未保存表单跨页及浏览器前进／后退保留；刷新和退出前提示。退出清除客户端偏好缓存。对响应版本单调校验，旧读取不能覆盖新保存；旧会话写响应不得回填新会话。
- 作品集色板中占比最大的真实代表色，按固定规则对应黑、白、灰、红、橙、黄、绿、青、蓝、紫、粉、棕的描述，如“黑色，深邃而沉稳”。这是画面色彩的编辑文案，不是人格推断，不会修改用户主动保存的偏好。
- 界面只保留用户需要的范围、状态和使用提示；采样、聚类与阈值等细节留在实现和文档中。

## 取舍

沿用一个演示账号，比增加完整注册与权限系统更符合当前展示范围，但同账号所有使用者共用作品和偏好。保存按钮明确区分修改草稿与生效设置；作品中的临时调整不会自动反推账号偏好。偏好发生冲突时需要重新读取再调整，避免丢失其他人的设置。

不增加设备档案、行为学习、训练数据捐赠、模型复评或 Agent。本记录不扩大既有模型和素材授权。
