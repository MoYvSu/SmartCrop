# ADR-0003：Venus 原生双路推理与报告结构化

状态：Accepted

日期：2026-09-04

## 背景

首轮 30 图真实部署回归仅通过 11 图。失败集中在让 Venus 一次性生成美学报告与裁剪框的
复杂 JSON：常见问题包括缺少字段、嵌套列表、JSON 截断和无效坐标。上传、队列、GPU、
制品下载与 120 秒超时机制没有出现系统性故障。

上游项目没有使用组合 JSON。AesGuide 评估使用独立的自然语言美学评论提示词，FLMS
评估使用独立的裁剪坐标提示词，并从 `(x1,y1),(x2,y2)` 形式提取坐标。旧演示也保留
模型完整评论，只单独解析裁剪框。

## 决策

worker 按三步串行执行：

1. 使用上游 AesGuide 原始提示词生成自由美学评论；
2. 使用上游 FLMS 原始提示词独立生成裁剪坐标，并兼容上游坐标点与旧演示数组格式；
3. 将前两步结果交给同一模型做纯文本结构化，输出产品报告。

两条视觉提示词使用与上游任务等价的简体中文表达。报告优先使用简体中文；若模型仍返回
有效英文报告则如实展示，不因语言回退而伪造或丢弃分析。每个结构化阶段最多重试一次。
worker 只记录输出长度、闭合状态和错误类型，不记录用户图片或模型评论正文。任何阶段连续
失败时仍按真实失败处理，不生成伪报告。

## 后果

- 模型先执行训练与评估中熟悉的任务，降低复杂 JSON 对视觉推理的干扰；
- 单任务包含多次串行生成，平均耗时会高于单次组合生成，但仍受 120 秒硬超时保护；
- 报告结构化只基于 Venus 原始评论和裁剪框，不引入额外模型或外部服务；
- 必须重新运行固定 30 图回归，以成功率、耗时和最终制品验证该方案。
