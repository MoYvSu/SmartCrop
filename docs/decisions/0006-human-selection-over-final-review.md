# ADR-0006：以人工选择替代终稿复评

状态：Accepted

日期：2026-09-06

## 背景

真实 Venus 探针确认三种偏好提示词能够分别完成初次裁剪推理，但没有证据证明模型能可靠比较复拍前后构图或稳定生成终稿复评报告。继续把复评放在公开主链路中，会让产品依赖一个已经确认不可靠的能力。

## 决策

- 公开产品以“三种偏好分别生成、用户选择和精修”为能力边界；
- 候选之间是否具有显著几何差异不再作为 P0.5 的能力门禁；
- 前端隐藏终稿复评入口，初始单图报告保留为辅助信息；
- API、契约、数据库字段和 worker 复评实现暂时保留，作为非公开实验接口，避免当前阶段产生破坏性迁移；
- 不把 `capability_status` 呈现为审美质量认证，界面只说明候选来源和人的决策责任。

## 后果

- 主流程不再受复评 JSON 输出不稳定影响；
- 用户仍可在三个偏好候选之间主动选择，并进行比例锁定精修；
- 后继版本可以在不恢复公开入口的情况下继续研究复评能力；
- 方案导出不再包含终稿复评字段，并显式记录人工选择模式；
- ADR-0005 的公开产品决策被本记录取代，其底层任务设计作为兼容实现保留。

## 恢复条件

只有模型或推理方法发生实质改进，并通过固定集稳定性测试和人工真实性复核后，才能提出恢复终稿复评或跨图比较功能的新 ADR。
