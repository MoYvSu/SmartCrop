# ADR-0002：一小时保留与共享访问码

状态：Accepted

日期：2026-09-01

## 决策

V1 不建立用户账号或历史。任务从创建起保留 1 小时，API 与 worker 周期性清理其独立任务目录与数据库记录。清理顺序固定为“先文件、后记录”；若文件删除失败，则保留过期记录并在下一轮重试，避免数据库已消失但用户文件仍滞留。所有 `/v1` 业务接口使用 `X-SmartCrop-Access` 共享访问码保护；部署侧负责 HTTPS 和按需限流。

## 边界

- 访问码必须从环境变量注入，不能提交到 Git；
- 访问码是受控演示门槛，不等同于多租户身份系统；
- 不能在清理机制和测试失效时继续宣称文件已删除；
- 日志不得记录上传内容或访问码。
