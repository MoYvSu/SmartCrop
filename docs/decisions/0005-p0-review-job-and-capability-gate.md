# ADR-0005：终稿复评任务与能力状态门禁

状态：Accepted

日期：2026-09-05

## 背景

Venus 论文和当前实现支持单图分析与裁剪，但没有直接证据证明模型能可靠比较两张不同图片的构图优劣。当前又没有可用 GPU，无法完成多候选差异性与复评质量验收。

## 决策

初始分析和终稿复评都作为显式任务进入同一 SQLite 队列，由串行 worker 执行。复评任务复制最终裁剪制品作为独立输入，不携带模型对话历史。浏览器、API 与 worker 通过版本化结构传递场景、比例、候选和父任务关系。

API 返回 `mock`、`unverified` 或 `verified` 能力状态。真实 Venus 部署默认是 `unverified`；只有 GPU 验收通过后才能由部署配置切换为 `verified`。

## 后果

- API 进程继续保持模型无关；
- 复评可以复用现有串行、超时和清理机制；
- UI 能清楚区分“链路可用”和“模型能力已验收”；
- 前后结果不是模型生成的相对排序，产品不得称为自动复拍效果验证。

## 验证证据

Mock 集成测试覆盖意图提交、三候选、比例约束、手动终稿、独立复评及方案下载。真实 Venus 验收延后至可用 GPU 环境。
