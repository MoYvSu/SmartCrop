# ADR-0010：共享演示账号与独立持久作品

状态：Accepted。日期：2026-10-17。

本记录采纳本轮账号与作品保存的实现决策，不代表真实模型能力、公开互联网部署或全部浏览器场景已经验收。它接续 [ADR-0009](0009-workspace-navigation-and-session-boundary.md)，替代其中“本阶段尚不实现账号、项目深链接与归档”的阶段性限制。

## 背景

摄影工作室需要跨次继续创作，并把已确认成片与随手调整区分开。旧 AI 任务的一小时保留期和共享访问码不能承担账号身份与长期作品存储：若作品只引用临时任务文件，任务清理后就会失效；若只在浏览器保存一个用户名，也不能阻止未授权读取图片。

因此，先实现单机、受控演示可用的真实认证与持久作品，不把弱模型升级为流程的强制前提，也不引入开放注册、多租户运营、自动画像或训练数据收集。

## 决策

### 1. 一个真实的共享演示身份

- 服务端维护一个当前配置生效的演示账号，默认用户名为 `demo`；同账号使用者共用作品库，彼此可以查看、修改和删除作品。这不是按访客隔离的个人空间，界面必须提示不要上传私人敏感照片。
- 不提供注册、找回密码、邮箱验证或管理员界面。用户名、展示名和初始密码由维护者通过服务端配置管理。
- `SMARTCROP_DEMO_PASSWORD` 优先用于初始化或变更密码；数据库只保存带随机盐、600,000 轮 PBKDF2-SHA256 的密码散列。改变密码会撤销该身份的现有会话；普通重启不重新生成散列或身份。
- 2026-10-19：演示默认密码改为 `123456`，非空环境变量优先覆盖；仅显式配置空字符串时，新账号生成随机密码到 `demo-credentials.txt`，已有账号保留其密码。移除环境变量恢复默认密码，API 下次启动会迁移旧密码并撤销旧会话，但账号 ID、作品和偏好保留。公网部署应另设强密码。
- 凭据文件不得是符号链接、硬链接或其他非常规文件。POSIX 检查文件归属并收紧为 `0600`；Windows 仍依赖数据目录的 NTFS 访问权限，不能把 mode 位当作权限保证。
- 若后续改用环境变量密码，旧自动生成文件在新散列提交后改为不含密码的说明，避免继续展示失效密码。密码不进入前端包、接口响应或应用日志。

### 2. Cookie 会话与写操作验证

- 登录生成随机会话令牌，通过 `smartcrop_session` Cookie 传递；Cookie 使用 `HttpOnly`、`SameSite=Lax` 和根路径，不放入浏览器长期存储。服务端仅保存令牌散列及用户归属、创建和到期时间。
- 默认会话绝对有效期为七天，可通过 `SMARTCROP_SESSION_TTL_SECONDS` 调整；读取会话不续期。重新登录替换当前 Cookie 对应的旧会话，退出删除该会话记录。
- 本机 HTTP 演示默认不设置 `Secure`；HTTPS 部署必须启用 `SMARTCROP_SESSION_COOKIE_SECURE=true`。这项开关不能替代 HTTPS 本身。
- 登录仅接受有大小限制的 JSON，并验证同源；使用 SQLite 保存每个实际客户端的登录尝试次数，默认十次／十五分钟。浏览器会话信息和 Cookie 不构成公开登录密码。
- 作品写操作和退出同时要求有效会话、`X-SmartCrop-CSRF` 验证值及同源信息。CSRF 是额外确认“操作来自本站页面”的验证，不是登录密码；只读图片下载仍需身份和作品归属，但不要求该验证值。
- 同源比较以服务端实际接收到的请求地址为准，不自行相信 `X-Forwarded-*`。反向代理须正确保留外部站点信息，并只让受信任的代理向应用提供转发协议；协议不一致时拒绝请求，不为方便而放宽验证。
- 账号、作品和任务接口响应不允许缓存；当前共享访问码仅保留兼容旧临时任务，不能充当作品账号，也不能绕过项目任务的归属检查。

### 3. 作品资源独立于 AI 任务

- 作品有独立 ID、账号归属、源图、预览、草稿和已归档版本，存入数据目录的 `projects/`，不依赖 `jobs/` 的一小时临时制品。
- 导入照片即可建立手动草稿；保存、归档和下载不要求先运行 AI。AI 只在用户主动请求后排队，GPU 推理仍沿用串行 worker。
- 每次归档记录当时的裁剪、发布意图、选择说明及参考来源，并生成对应成片。继续编辑更新草稿，不悄悄替换已归档版本；版本查询和版本下载仍校验作品归属。
- AI 的候选、报告、能力来源标识及状态另存为项目参考快照；worker 和项目读取会整理该快照，使临时任务清理后仍可查看已有参考。晚到结果不能直接覆盖人工草稿。
- 候选选择记录其原始参考任务，重新生成 AI 参考不能把旧选择伪装成来自新结果。Mock、真实运行与前端固定样例不能混成“已验证模型能力”；固定样例不进入个人作品库。
- 项目关联的旧 `/v1/jobs/{id}` 和制品路径同样校验账号归属。禁止通过关联任务的旧 `/review` 端点再派生无归属的复评任务；可靠终稿复评不在本产品能力范围内。

### 4. 保留、删除与元数据

- 持久项目的草稿和归档均保留至用户主动删除，不采用早期设计草案中的二十四小时草稿自动清理提议。旧临时任务及其推理副本仍按独立的一小时规则处理。
- 删除作品会删除其项目文件、草稿与归档版本记录；项目任务关联保留不可访问的删除标记，避免旧链接因关联丢失而退化为匿名制品。已经提交的推理副本仍由临时任务规则处理，不宣称删除按钮立即清除一切副本。
- 不承诺备份、浏览器已下载文件或外部副本被同步删除，也不宣称物理介质上的数据不可恢复。维护者须将备份保留范围单独告知使用者。
- 持久源图采用重新构建像素并编码的方式，剥离上传文件的全部附带元数据，包括 EXIF、GPS、设备序列号和 PNG 文本，不保存上传文件原始字节。方向校正后的像素图是后续裁剪来源。
- 不因剥离元数据而推测相机参数，也不承诺原文件的色彩配置或文件字节保持不变。2026-10-19 按 [ADR-0013](0013-camera-exif-whitelist.md) 单独保存拍摄参数白名单；不恢复或保存整份 EXIF。

### 5. 并发与部署约束

- 草稿保存和归档必须携带当前 `revision`。服务器仅在版本号仍匹配时更新；否则返回 `409`，不静默覆盖另一标签页的修改。这是“先确认版本没变，再保存”的并发保护，而不是自动合并。
- 创建、保存与归档的成功响应来自本次写入事务内的快照，不能在提交后重新读取并误带回另一写者的后继 revision。跨标签登录轮换导致写入校验失效时，只同步校验信息并保留调整，由用户主动重试，不自动重放导入或归档。
- 文件操作使用单个 API 进程内的操作锁，数据库更新使用 SQLite 事务。当前交付边界是单主机、单 API 进程与串行推理 worker；不能由此宣称多 API 实例、共享网络盘或多主机部署已经安全验证。
- 数据库保存账号、会话、作品与任务关联，文件目录保存图像资源。二者是一个完整状态；只复制其中之一不能构成可恢复的作品备份。
- 维护者应在受控停写窗口同时备份数据库和数据目录，或使用有一致性保证的 SQLite 备份方式并协调文件快照；直接复制正在写入的主数据库文件不能被当作已验证备份。恢复后仍需检查文件、身份归属和版本对应关系。
- 数据目录、数据库、会话、初始凭据和备份均须置于 Git 之外。当前没有自动备份、容量配额、存储加密或公开多访客隔离能力，部署维护者承担访问控制和容量管理责任。

## 替代方案与取舍

纯浏览器伪登录和照片缓存实现简单，但不能提供服务端身份或稳定归属，因此不采用。沿用一小时任务作为作品来源同样简单，却无法满足跨次继续编辑，因此引入独立项目资源。

完整账号平台、对象存储和多实例数据库能够扩展运营能力，但超过受控比赛演示的当前需要；本轮不实现。共享演示账号降低维护成本，代价是同账号访客没有彼此隔离，不能以“已登录”包装成私密个人服务。

全部剥离图像元数据减少不必要的隐私留存，代价是当前不提供持久 EXIF 摄影参数；该取舍必须在产品界面保持诚实。

## 验证依据与待验范围

实现入口为 [认证模块](../../apps/api/src/smartcrop_api/auth.py)、[项目存储](../../packages/runtime/src/smartcrop_runtime/projects.py)、[项目接口](../../apps/api/src/smartcrop_api/projects.py)及 [API 集成](../../apps/api/src/smartcrop_api/app.py)。

[认证测试](../../tests/test_auth.py)覆盖会话过期、轮换、退出与密码变更撤销、来源与 CSRF、跨客户端隔离、凭据文件安全和并发限速；[项目测试](../../tests/test_projects.py)覆盖元数据剥离、版本冲突、归档不变性、临时任务清理后的独立参考与失败恢复。项目任务不得派生匿名复评的回归及既有临时任务复评兼容测试已单独运行通过。

测试描述不等于公开部署安全审计、备份恢复演练或模型质量证明。Windows 当前不具备创建符号链接的测试权限，且 POSIX 文件权限用例不适用于 NTFS；对应跳过项不能写成已验证。整轮测试及浏览器验收以交付记录为准。
