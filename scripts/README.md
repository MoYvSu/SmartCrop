# Repository scripts

Keep repeatable development, validation, migration, and deployment helpers here. Scripts must not embed personal absolute paths or secrets.

- `dev.py`：本地 Mock API 与 worker 联调。
- `run_regression.py`：部署后的基础 30 图全链路回归。
- `run_p0_capability_probe.py`：P0 三候选、比例约束与终稿复评结构探针；美学差异仍需人工复核。
