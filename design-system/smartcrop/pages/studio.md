# SmartCrop 摄影编辑室页面规范

更新日期：2026-10-17。适用于首页、上传表单、任务进度、裁剪工作台和报告面板。

本文件是 `design-system/smartcrop/MASTER.md` 的页面覆盖规范。保留 MASTER 作为早期设计记录；本次页面以这里的布局、配色、字体层级与响应式行为为准。

## 视觉方向

以摄影编辑室和编辑杂志为参照：暖白纸面、森林绿工具、鼠尾草底色、清楚的网格，以及大面积真实照片。内容的丰富来自照片、创作场景和操作说明，而非虚构数据或增加模型能力承诺。

UI/UX Pro Max 的 Photo Editor 检索支持采用 Product Demo + Features、清晰网格与轻量反馈。自动建议的暗紫色不适合本次暖色摄影方向，未沿用。下面的配色为本项目人工选择，并需要结合实际页面检查文字对比。

## 色彩

| 用途 | 值 | 页面作用 |
| --- | --- | --- |
| 页面底色 | `#F6F5F1` | 暖白背景，承托照片 |
| 卡片底色 | `#FFFEFA` | 上传、工具和报告 |
| 主色 | `#275C4C` | 主要按钮、品牌和当前步骤 |
| 强调色 | `#315F50` | 标题注记、图标、交互焦点 |
| 鼠尾草 | `#E5ECDF` | 已选项和次级信息底色 |
| 低饱和酸橙 | `#D4E6A0` | 深绿宣言区的少量装饰 |
| 主文字 | `#252D29` | 正文、标题和表单 |
| 次级文字 | `#626C64` | 解释、提示和图片说明 |
| 图像工作区 | `#202622` | 原图、裁剪预览；保持中性深色 |

照片叠字应有深色渐变或实色衬底，避免依赖原图的局部明暗。酸橙用于点缀和深色背景中的视觉提示，不用于白底小字。

## 字体与节奏

- 中文沿用系统无衬线字体栈，不额外依赖网络字体。英文与正文保持同一字体家族；步骤编号可使用系统衬线字体增加编辑感。
- 首页大标题桌面约 48–55 px，手机约 32–44 px；正文约 14–16 px，表单标签与说明约 12–13 px，装饰性英文注记可更小，但不承载操作必需信息。
- 首页宽度上限 1280 px；裁剪工作台可扩展至 1680 px。卡片内留白约 24 px，主要区块间距约 32–64 px。
- 圆角以 12–22 px 为主，阴影克制；按钮悬停改变颜色和阴影，不移动周围布局。

## 页面结构

1. 品牌导航：创作工作台、构图灵感、使用指南，以及现有清理政策提示。
2. 三步进度：上传照片、AI 构图、精修与下载。已完成与当前步骤同时使用数字/勾选和文字表达。
3. 创作首屏：左侧摄影标题与构图示意，右侧上传、场景、发布模板和访问码。
4. 发布场景：社交封面、演示配图、商品主图。点击同步现有场景和模板选择，不上传示意照片、不自动启动分析。
5. 使用指南：上传设定、探索候选、精修下载。
6. 创作宣言：强调最终选择属于用户，避免暗示 AI 有唯一审美结论。
7. 裁剪结果：维持图像先于候选与辅助工具的顺序，增加清楚的工作区标题；报告保持解释 AI 初始建议的边界。

## 响应式与交互

- 1440 px：双栏创作首屏、三张横排场景卡。足够宽时结果页使用工作区与报告双栏。
- 1024 px：收紧双栏间距，移除重复的页眉政策说明，完整说明仍在上传卡保留；结果报告回到页面正常流。
- 768 px 附近：创作区转为单列，场景卡转换为横向图片卡片，指南逐项排列。核心上传与表单均可使用。
- 375 px：完整操作链路仍显示，工具按钮换行，对照图单列，输入字号保持 16 px 以减少手机浏览器自动放大。
- 无固定顶栏，键盘焦点不会被其遮住。触控目标最少 44 CSS px；保留跳到主要内容、可见焦点、键盘裁剪支持与原有错误/状态说明。
- 动效只承担轻量反馈，不引入自动轮播、视差或必须等待动画才能读到的内容；尊重 `prefers-reduced-motion`。
- 原图仅压暗裁剪框外的区域，框内保留原始亮度。原图与预览共用中性深色舞台，避免空白底色干扰判断。
- “精细调整”默认折叠，放在原图下方，提供四向移动及扩大、缩小按钮。手机和不能拖动的用户也可完成裁剪；固定比例缩放保持对角锚点。
- 保存和下载期间锁定裁剪、候选及选择依据，按钮显示进行中状态；完成后给出明确反馈，避免重复提交或旧响应覆盖新调整。
- 切换候选后焦点返回展开按钮。轮询断线时保留当前任务，可重新连接同一任务；过期后保留预览、停止编辑并引导重新上传。

## 内容与图片边界

首页三张摄影素材用于展示气质和发布场景。构图覆盖线是固定视觉示意，必须明确标注“非 AI 推理结果”。场景卡应说明实际分析对象为用户上传的照片。素材出处单独保存在素材说明中。

不增加评分、真实用户数量、获奖徽标或未经证实的模型效果描述。不恢复已经撤下的复拍比较、终稿复评和 JSON 导出入口。
