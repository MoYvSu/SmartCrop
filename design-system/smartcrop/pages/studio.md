# SmartCrop 摄影编辑室页面规范

更新日期：2026-10-17。适用于首页、上传表单、任务进度、裁剪工作台和报告面板。

本文件是 `design-system/smartcrop/MASTER.md` 的页面覆盖规范。保留 MASTER 作为早期设计记录；本次页面以这里的布局、配色、字体层级与响应式行为为准。

## 视觉方向

以摄影编辑室和编辑杂志为参照：暖白纸面、森林绿工具、鼠尾草底色、清楚的网格，以及大面积真实照片。内容的丰富来自照片、创作场景和操作说明，而非虚构数据或增加模型能力承诺。

UI/UX Pro Max 的 Photo Editor 检索支持采用 Product Demo + Features、清晰网格与轻量反馈。自动建议的暗紫色不适合本次暖色摄影方向，未沿用。下面的配色为本项目人工选择，并需要结合实际页面检查文字对比。

## 色彩

| 用途 | 值 | 页面作用 |
| --- | --- | --- |
| 页面底色 | `#F6F5F1` | 暖白背景，承托照片 |
| 卡片底色 | `#FFFEFA` | 上传、工具和报告 |
| 主色 | `#275C4C` | 主要按钮、品牌和当前步骤 |
| 强调色 | `#315F50` | 标题注记、图标、交互焦点 |
| 鼠尾草 | `#E5ECDF` | 已选项和次级信息底色 |
| 低饱和酸橙 | `#D4E6A0` | 深绿宣言区的少量装饰 |
| 主文字 | `#252D29` | 正文、标题和表单 |
| 次级文字 | `#626C64` | 解释、提示和图片说明 |
| 图像工作区 | `#202622` | 原图、裁剪预览；保持中性深色 |

照片叠字应有深色渐变或实色衬底，避免依赖原图的局部明暗。酸橙用于点缀和深色背景中的视觉提示，不用于白底小字。

## 字体与节奏

- 中文沿用系统无衬线字体栈，不额外依赖网络字体。英文与正文保持同一字体家族；步骤编号可使用系统衬线字体增加编辑感。
- 首页大标题桌面约 48–55 px，手机约 32–44 px；正文约 14–16 px，表单标签与说明约 12–13 px，装饰性英文注记可更小，但不承载操作必需信息。
- 首页宽度上限 1280 px；裁剪工作台可扩展至 1680 px。卡片内留白约 24 px，主要区块间距约 32–64 px。
- 圆角以 12–22 px 为主，阴影克制；按钮悬停改变颜色和阴影，不移动周围布局。

## 页面结构

1. 品牌导航：创作工作台、构图灵感、使用指南，以及现有清理政策提示。
2. 三步进度：上传照片、AI 构图、精修与下载。已完成与当前步骤同时使用数字/勾选和文字表达。
3. 创作首屏：左侧摄影标题与构图示意，右侧上传、场景、发布模板和访问码。
4. 发布场景：社交封面、演示配图、商品主图。点击同步现有场景和模板选择，不上传示意照片、不自动启动分析。
5. 使用指南：上传设定、探索候选、精修下载。
6. 创作宣言：强调最终选择属于用户，避免暗示 AI 有唯一审美结论。
7. 裁剪结果：维持图像先于候选与辅助工具的顺序，增加清楚的工作区标题；报告保持解释 AI 初始建议的边界。

## 响应式与交互

- 1440 px：双栏创作首屏、三张横排场景卡。足够宽时结果页使用工作区与报告双栏。
- 1024 px：收紧双栏间距，移除重复的页眉政策说明，完整说明仍在上传卡保留；结果报告回到页面正常流。
- 768 px 附近：创作区转为单列，场景卡转换为横向图片卡片，指南逐项排列。核心上传与表单均可使用。
- 375 px：完整操作链路仍显示，工具按钮换行，对照图单列，输入字号保持 16 px 以减少手机浏览器自动放大。
- 无固定顶栏，键盘焦点不会被其遮住。触控目标最少 44 CSS px；保留跳到主要内容、可见焦点、键盘裁剪支持与原有错误/状态说明。
- 动效只承担轻量反馈，不引入自动轮播、视差或必须等待动画才能读到的内容；尊重 `prefers-reduced-motion`。
- 原图仅压暗裁剪框外的区域，框内保留原始亮度。原图与预览共用中性深色舞台，避免空白底色干扰判断。
- “精细调整”默认折叠，放在原图下方，提供四向移动及扩大、缩小按钮。手机和不能拖动的用户也可完成裁剪；固定比例缩放保持对角锚点。
- 保存和下载期间锁定裁剪、候选及选择依据，按钮显示进行中状态；完成后给出明确反馈，避免重复提交或旧响应覆盖新调整。
- 切换候选后焦点返回展开按钮。轮询断线时保留当前任务，可重新连接同一任务；过期后保留预览、停止编辑并引导重新上传。

## 内容与图片边界

首页三张摄影素材用于展示气质和发布场景。构图覆盖线是固定视觉示意，必须明确标注“非 AI 推理结果”。场景卡应说明实际分析对象为用户上传的照片。素材出处单独保存在素材说明中。

不增加评分、真实用户数量、获奖徽标或未经证实的模型效果描述。不恢复已经撤下的复拍比较、终稿复评和 JSON 导出入口。

设计研究与比赛作品链接见 [本轮设计记录](../../../docs/design/studio-refresh-2026-10.md)。CMIT 作品展示提供视觉参考，不等同于比赛评分规则。

## 宽屏工作室 V2 第一阶段覆盖

本节覆盖上文涉及旧全局流程和结果页结构的描述，配色、字体与展示首页的摄影语言继续沿用。

- 展示首页保留摄影首屏、上传与场景区，导航增加“进入工作室”；不再在应用所有页面重复三步进度。
- 应用采用 216 px 侧栏、64 px 顶栏和五个平级入口：创作概览、构图工作台、我的作品、摄影洞察、摄影档案。
- 工作台默认单主画布，裁剪、成片预览、对照按需切换；右侧 320 px 工具区承载候选与折叠报告，保持暖白工具与中性深色照片舞台。
- 五页切换不清空当前编辑；仅在真实操作结束、失败或连接中断时呈现相应状态，不以切页重置模型任务。
- 图像分析、EXIF、账号及长期作品保存未接入的部分明确说明，不显示伪造图表、登录状态或已归档记录。

实际交付与六尺寸浏览器验证见 [V2 第一阶段记录](../../../docs/design/desktop-workspace-v2-phase-1.md)；完整目标与后续保存规则见 [V2 主设计](../../../docs/design/desktop-workspace-v2.md)，不能把全部设计目标理解成已完成能力。

## 宽屏工作室 V2 第二阶段覆盖

本节进一步覆盖第一阶段“账号与长期作品未接入”及旧全局三步 AI 流程的描述。五页框架、暖白森林绿、照片优先和 320 px 工具区保持不变。

- 登录是实际演示账号，不再以共享访问码冒充身份。用户名可预填 `demo`，密码为空；支持密码管理器、粘贴及显示／隐藏密码，不增加未实现的注册或找回按钮。
- 登录页、侧栏、概览、作品页与档案明确“演示账号共用作品库”。使用同一账号的人都能查看、修改项目，不暗示只有自己可见；不要上传私人敏感照片。
- 导入先建立独立作品草稿并直接进入手动编辑，AI 按需请求。展示指南采用“导入，建立草稿／精修，参考按需／归档，下载成片”，不把获取三种候选设为必经步骤。
- 持久化工作台使用真实草稿保存状态，脏状态显示“有更新待保存”；完成后“完成并归档”，继续修改后“保存新版本”。归档期间只在归档动作显示对应进行中状态。
- AI 生成时不锁住本地精修，返回仅更新参考，不能自动覆盖期间裁剪。报告仍只解释最初参考；不恢复终稿复评和复拍比较。
- 持久项目候选统一标为“构图参考／参考方向”，不是自动采用的“当前方案”。第一条也有“采用此构图参考”入口；替换草稿须主动选择并确认。
- 概览显示真实项目统计与最近六项。未读取、读取中或失败显示 `—`，只有成功的空列表才是真实的零；样例和同项目版本不得重复计数。
- 作品页支持标题搜索、草稿／归档筛选与真实状态重试。草稿缩略图标“原图预览”，归档卡显示固定成片；草稿变更提示不得与归档下载混淆。
- 删除确认明确删除草稿、版本和图片、不可撤销，并说明影响同一账号的所有使用者。无当前会话时不在真实作品库下重复放置“没有正在进行创作”空块。
- 项目照片、草稿和归档成片保留至主动删除，不能沿用临时任务一小时过期提示。图像副本去除元数据且不保存 GPS，图像分析与 EXIF 仍标“尚未接入”。
- 固定样例保持访客可用、明确固定结果来源，不保存为账号项目，也不进入统计。偏好与摄影洞察仍未接通，不用模拟数据或默认下载推断用户喜好。

接入范围、状态规则及本轮验证边界见 [V2 第二阶段记录](../../../docs/design/desktop-workspace-v2-phase-2.md)。照片、草稿和成片的实际保存与访问控制仍须以服务行为和集成测试确认。

## 宽屏工作室 V2 第三阶段覆盖

本节覆盖第二阶段“图像分析与摄影洞察未接通”的描述，保留既有配色和照片优先布局。

- 工作台右侧默认打开图像分析；当前裁剪／完整原图切换不改变裁剪框，旧结果在范围改变时立即隐藏，再去抖计算。
- 使用森林绿基础条形直方图与真实主色色板，不使用随机曲线、装饰仪表盘或模型评分。色相仅统计有彩部分，灰阶不伪造红色；透明像素以可见权重处理。
- 每张分布图有文字、数值与可键盘展开的数据表，主色配 HEX、RGB 及占比。图形颜色只是辅助，不能独自承担语义。
- 宽屏工具区独立滚动、顶部工具标签固定，设置滚动焦点安全区；窄屏仍正常页面流。图表缩放自适应，精确读数可展开表格。
- 摄影洞察提供全部／近30天／近90天，真实覆盖与错误计数、等作品权重的像素汇总、冻结用途与画幅及参与作品列表。只用每项目最新归档，草稿不计入、多次归档不重复计数。
- 空库、尚未读取、局部失败、透明作品各自说明，不以静态示例或默认零值填图；可重试或回到真实作品继续编辑。
- 不扩展为 EXIF、设备档案、模型终稿复评或个人画像；“本机计算”不能暗示照片不再按已有规则保存在服务器。

实现与验收见 [V2 第三阶段记录](../../../docs/design/desktop-workspace-v2-phase-3.md)，算法口径见 [ADR-0011](../../../docs/decisions/0011-browser-pixel-analysis-and-archive-statistics.md)。

## 宽屏工作室 V2 第四阶段覆盖

- 摄影档案改为可保存的创作偏好表单：常用用途、裁剪比例与模板、自定义宽高、辅助线；明确新建采用、已有作品不变。
- 反馈覆盖读取、保存、成功、错误及冲突；未保存输入跨页保留，刷新和退出提示。表单控件带标签和焦点，44 px 最小高度；窄屏辅助线单列。
- 新建导入采用账号偏好；本次主动选择优先，不被后台读取覆盖。辅助线随独立作品保存，但不写入照片。
- 作品集主色增加固定“色彩气质”文案，例“黑色，深邃而沉稳”。精简聚类等实现说明，保留必要范围、状态和共享账号提示。

实现与验收见 [V2 第四阶段记录](../../../docs/design/desktop-workspace-v2-phase-4.md)，持久化约定见 [ADR-0012](../../../docs/decisions/0012-account-defaults-and-project-guide-snapshots.md)。

摄影档案身份卡收尾：采用已授权灵感封面、取景框线、光圈头像、真实作品计数和当前偏好摘要，保留森林绿与暖白。封面明确标注灵感素材，不冒充用户作品。摘要只在保存后更新；未知计数显示 `—`，辅助线名称整项换行。右侧表单保持原样，不新增身份等级或虚构成绩。
